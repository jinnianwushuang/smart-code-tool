# AIGC-TOOL-DATA-VERIFICATION — AIGC 工具数据联网核对与更新

> **指令用途**：联网查询当下最新的 AIGC 工具生态数据，核对并更新文档站 AIGC 模块中所有涉及工具版本、价格、功能、市场格局的内容。
>
> **触发方式**：直接发送指令名 `AIGC-TOOL-DATA-VERIFICATION` 或选中本文件标题运行。

---

## 一、执行流程

### 第 1 步：联网搜索（必须联网，禁止使用过时数据）

按以下 5 个维度分别联网搜索，获取**当月最新**数据：

| 维度         | 搜索关键词示例                             |
| ------------ | ------------------------------------------ |
| AI 绘画/设计 | `2026年最新AI绘画工具排行 Midjourney Flux` |
| AI 视频生成  | `2026年最新AI视频生成工具排行 可灵 即梦`   |
| AI 音乐/配音 | `2026年最新AI音乐创作工具 Suno Udio`       |
| AI 数字人    | `2026年最新AI数字人工具排行 HeyGen`        |
| AI 接单变现  | `2026年最新AI接单平台 闲鱼 小红书`         |

**搜索原则**：

- 每个维度至少搜索 2-3 个不同关键词
- 优先采信权威来源（36氪、量子位、机器之心、少数派、官方公告）
- 关注版本号变化、新工具上线、旧工具停服、价格调整

### 第 2 步：对比差异

将联网搜索到的最新数据，与现有文档内容逐项对比，记录差异：

```
差异记录格式：

- 过时内容：可灵 AI 3.0
- 最新数据：可灵 AI 4.0（2026.8 发布）
- 变更类型：版本号升级 / 新增工具 / 工具停服 / 价格调整
```

每个文件头部的核对日期必须更新为当天日期：

```markdown

```

### 第 5 步：输出变更摘要

## 二、更新规范

### 工具信息更新规范

| 字段     | 说明                   | 示例                        |
| -------- | ---------------------- | --------------------------- |
| 版本号   | 以官方最新为准         | 可灵 AI 3.0 → 4.0           |
| 价格     | 以官网当日报价为准     | $29/月 → $24/月起           |
| 核心优势 | 用一句话概括最大卖点   | 国产标杆，运动一致性强      |
| 适合场景 | 2-4 字                 | 短视频、广告                |
| 新增工具 | 确认已上线且可用才收录 | 商汤 Seko（2026.7 上线）    |
| 停服工具 | 标注停服日期，不删除   | Sora 已死（2026.4.26 关停） |

### 核对日期标注规范

- **位置**：每个文件头部 blockquote 内，紧跟原始描述之后
- **格式**：`> **内容核对于 YYYY.MM.DD**，后续有再次联网核对变更时更新。`
- **日期**：使用执行核对当天的日期
- **范围**：所有包含具体工具名称/版本号/价格的 AIGC 文档

## 三、注意事项

1. **必须联网搜索**，禁止凭记忆或训练数据填写，AIGC 工具迭代极快
2. **版本号必须精确**，不要写"最新版"这种模糊表述
3. **价格以官网为准**，搜索时注意区分月付/年付/credits
4. **新工具收录标准**：已正式上线 + 有免费或付费入口 + 至少 2 个权威来源报道
5. **停服工具处理**：标注停服日期，保留历史记录，不直接删除
6. **同步更新导航配置**：`aigc-config.js` 中的数据也要同步
