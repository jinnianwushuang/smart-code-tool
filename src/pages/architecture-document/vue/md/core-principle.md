## 架构核心原理：零件、装配与调度

本架构基于“一切皆对象”的设计哲学，将复杂的页面逻辑拆解为标准化的工业流程。

## 1. 核心公式

> **零件（属性 + 方法）+ 装配+ 调度（Vue 生命周期/监听）= 页面**

## 2. 零件库 (Atoms)

## 零件：属性 (State )

| 类型         | 说明                         | 对应 Vue 概念       |
| :----------- | :--------------------------- | :------------------ |
| **内部状态** | 组件私有的响应式数据、状态机 | `ref`, `reactive`   |
| **衍生状态** | 基于基础数据计算而来的逻辑   | `computed`          |
| **外部输入** | 父组件透传的只读数据         | `defineProps`       |
| **共享状态** | 全局或模块间的共享数据       | `Pinia` / `Vuex`    |
| **常量配置** | 静态配置（全局）             | `project-common.js` |
| **常量配置** | 静态配置（模块/本地）        | `config.js`         |

## 零件：方法 ( Methods)

| 类型         | 说明                             | 对应 目录、文件                |
| :----------- | :------------------------------- | :----------------------------- |
| **业务逻辑** | 组件私有业务逻辑函数             | `模块/module/`                 |
| **接口调度** | 组件私有API请求逻辑函数          | `模块/api-request/`            |
| **状态变更** | 原 `VUEX` 中的 `Setter` 函数     | 直接引入使用                   |
| **全局工具** | 如日期格式化、消息提示等通用函数 | `project-common.js`            |
| **事件派发** | 派发事件生成器                   | `模块/emit/index.js`           |
| **Vue监听**  | Vue 监听注册器                   | `模块/watch/index.js`          |
| **原生监听** | DOM事件监听注册器                | `模块/event-listener/index.js` |
| **事件总线** | Mitt 注册器                      | `模块/mitt/mitt-pipeline.js`   |

## 3. 装配流水线 (Assembly)

## 属性装配 (State Assembly)

- **单元逻辑属性组合：** 将上述“零件：属性”（不包含 props）按流程业务逻辑封装。
- **组件属性集成：** 多个“单元逻辑属性组合” + `props` 的最终聚合。

## 方法装配 (Method Assembly)

- **单元逻辑方法组合：** 将上述“零件：方法”按流程业务逻辑封装。
- **组件方法集成：** 多个“单元逻辑方法组合”的最终聚合。

## 4. 调度与页面激活 (Orchestration)

- **生命周期：** 在“方法装配”过程中，编写生命周期钩子调度代码，负责组件的激活、调度与资源销毁。
- **监听调度：** 在“方法装配”过程中，将内部的监听逻辑 (Watch/Event) 注入 Vue 运行环境。
- **最终呈现：** 将聚合后的 Data 和 Methods 暴露给 `Template` 使用

## 5. 调试指南

调试逻辑非常简单，当需要定位逻辑源头时，请按以下**优先级**进行排查：

1. **当前组件目录：** 查看所在目录下的局部逻辑块。
2. **composable-common：** 查看模块内的通用组合逻辑。
3. **project-common：** 查看项目级的公共逻辑。
4. **store-common：** 针对 VUEX 等明显单例特征的状态。
