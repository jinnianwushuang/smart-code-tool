这份白皮书为您最终确定了**“本地高性能计算 + 云端轻量化管控”**的工业级架构方案。它既保证了源码在客户端处理的安全性与极速体验，又实现了团队管理所需的数字化资产沉淀。

---

## 🛡️ 前端代码质量分析平台技术选型白皮书 -V2.0

## 一、 项目定位

构建一个**“安全、极速、数字化”**的代码质量度量体系。通过本地化分析保护源码隐私，通过云端数据汇总实现团队代码质量的横向对比与长期成长曲线追踪。

---

## 二、 核心架构设计：重量客户端 + 轻量服务端

- **客户端 (The Engine)**：负责重计算、大文件 I/O、AST 深度解析。
- **服务端 (The Hub)**：负责数据持久化、质量趋势计算、项目组权限管控、报告分发。

---

## 三、 详细技术栈清单

## 1. 客户端：高性能分析引擎 (Desktop & CLI)

| 维度         | 技术选型           | 说明                                                          |
| :----------- | :----------------- | :------------------------------------------------------------ |
| **容器/壳**  | **Electron**       | 桌面端交互界面，提供文件系统访问能力。                        |
| **UI 框架**  | **Vue 3 + Quasar** | 利用 Quasar 的 **Electron Vite** 模式实现极速开发与组件复用。 |
| **核心逻辑** | **Rust**           | 承载文件扫描、正则检索、AST 转换等高密度计算任务。            |
| **解析器**   | **Oxc / SWC**      | 工业级 Rust 代码解析库，主打万级文件秒级处理。                |
| **通信层**   | **NAPI-RS**        | 将 Rust 编译为原生 Node 模块，实现 JS 与 Rust 的零成本调用。  |
| **本地缓存** | **SQLite**         | 用于断网环境下的数据暂存及重复扫描时的增量优化。              |

## 2. 服务端：质量数据中心 (Backend & Dashboard)

| 维度         | 技术选型             | 说明                                                     |
| :----------- | :------------------- | :------------------------------------------------------- |
| **开发框架** | **NestJS (Node.js)** | 企业级框架，与前端 TS 类型生态完美契合。                 |
| **数据库**   | **PostgreSQL**       | 存储项目元数据、用户信息及质量快照。                     |
| **时序引擎** | **TimescaleDB**      | 基于 PG 的插件，专门优化“代码质量随时间变化”的趋势查询。 |
| **认证授权** | **JWT / SSO**        | 支持企业内部身份认证，区分不同项目组权限。               |

## 3. 工程化与交付 (CI/CD & DevOps)

| 维度         | 技术选型            | 说明                                                              |
| :----------- | :------------------ | :---------------------------------------------------------------- |
| **集成方式** | **Headless CLI**    | 封装 Rust 逻辑为独立二进制文件，直接在 GitLab CI/Jenkins 中运行。 |
| **报告生成** | **Puppeteer**       | 将 Vue 报表页面动态转换为 PDF 格式进行推送。                      |
| **通信协议** | **Protobuf / JSON** | 客户端分析结果上报至服务端的标准协议。                            |

## 四、 关键评估指标 (Metrics)

平台将围绕以下维度生成代码质量画像：

1. **复杂性控制**：圈复杂度 (Cyclomatic)、认知复杂度 (Cognitive)。
2. **代码冗余**：重复率检测 (CPD - Copy Paste Detection)。
3. **技术债**：TODO 统计、过时 API 使用情况。
4. **维护性**：模块依赖深度、扇入扇出比 (Fan-in/out)。
5. **规范执行**：结合 ESLint 规则的自动评分。

---

## 五、 方案优势 (Value Proportions)

- **极致性能**：Rust 引擎确保分析过程不卡顿，即便在 10W+ 行规模的项目中也能实现“所改即所得”。
- **数据安全**：**源码不出本地**。服务端仅接收统计后的指标 JSON，不接触任何核心业务逻辑代码。
- **成长可视**：通过轻量服务端记录的“成长曲线”，管理层可以直观看到团队技术债务的清理进度。
- **低耦合性**：Quasar 组件库确保了 UI 的一致性，且未来可轻松扩展为 H5 端查看报表。

## 六、 实施路线图 (Next Steps)

1. **原型阶段**：使用 Quasar + Electron + NAPI-RS 跑通“本地扫描一个文件夹并显示文件数”。
2. **核心开发**：集成 Oxc 解析器，实现基本的“圈复杂度”和“依赖关系”提取。
3. **上报测试**：开发 NestJS 接口，实现客户端分析数据自动推送到后端并入库。
4. **可视化完善**：在前端加入 G6 依赖图谱和 ECharts 趋势图，完成周报自动生成功能。
