# AI 写作避坑指南

> 赚钱很重要，不踩坑更重要。

---

## 一、版权风险

### AI 生成内容有没有版权？

**现状（2026.10）**：法律还在完善中，但有几个基本原则：

| 情况                     | 风险等级 | 说明           |
| ------------------------ | -------- | -------------- |
| 自己用 AI 写着玩         | 低       | 没人管         |
| AI 辅助写 + 大量人工修改 | 低       | 算你的创作     |
| 直接发 AI 原文           | 中       | 可能被平台降权 |
| AI 生成内容直接商用      | 中       | 版权归属有争议 |
| 用 AI 模仿特定作者风格   | 高       | 可能侵权       |

### 安全做法

1. **AI 出初稿，人工做修改** — 至少改 30% 以上
2. **加入个人经历和观点** — 这是 AI 编不出来的
3. **不要直接复制 AI 原文去商用** — 加工后再用
4. **客户要求商用时提前说明** — 版权归属写清楚

## 二、平台规则

### 各平台对 AI 内容的态度

| 平台   | 态度         | 说明                             |
| ------ | ------------ | -------------------------------- |
| 小红书 | 容忍但有条件 | 不能直接发 AI 原文，需要二次加工 |
| 抖音   | 需要标注     | AI 生成内容需标注"AI 生成"       |
| 公众号 | 容忍         | 目前没有严格限制                 |
| 知乎   | 较严         | 检测到 AI 内容可能限流           |
| 闲鱼   | 不管         | 只关心交易是否合规               |

### 避免被平台惩罚

1. **不要批量发布相似内容** — 平台会判定为垃圾信息
2. **不要直接复制 AI 原文** — 查重率太高会被限流
3. **每篇都要有独特性** — 换角度、换风格、加个人元素
4. **不要一天发太多** — 小红书每天 1-2 篇就够

## 三、常见骗局

### 必须远离的四类骗局

| 骗局            | 特征               | 应对                         |
| --------------- | ------------------ | ---------------------------- |
| 高价培训课      | "学完月入过万"     | 免费工具就能上手，别花冤枉钱 |
| AI 挂机赚钱     | "挂机自动收益"     | 全是假的，没有一个是真的     |
| 先交押金/保证金 | "接单前先交 XX 元" | 正规平台不需要你先掏钱       |
| 代运营加盟      | "交加盟费换资源"   | 资源是假的，骗加盟费的       |

### 铁律

```
正规接单 = 客户给你钱
凡是让你先转账的 = 诈骗
```

## 四、接单常见坑

### 客户方面的坑

| 坑       | 表现                   | 预防                          |
| -------- | ---------------------- | ----------------------------- |
| 白嫖党   | 看完稿子不付款         | 先收定金，发水印预览          |
| 无限改稿 | "再改改""还不太对"     | 提前约定修改次数（最多 2 次） |
| 需求模糊 | "你看着办"             | 需求确认表填完再开工          |
| 拖延付款 | "做完了一起结"         | 小额全款，大额分期付款        |
| 恶意差评 | 闲鱼上给了差评威胁退款 | 保留聊天记录，平台申诉        |

### 自我保护清单

- [ ] 开工前确认需求（文字记录）
- [ ] 收定金再开工
- [ ] 约定修改次数
- [ ] 约定交付时间
- [ ] 保留所有聊天记录
- [ ] 不做违规内容（论文代写、虚假宣传等）

## 五、AI 写作的道德边界

### 可以做的

- 用 AI 辅助写文案 → ✅
- 用 AI 生成初稿再修改 → ✅
- 用 AI 帮客户优化简历 → ✅
- 用 AI 写营销文案 → ✅

### 不建议做的

- 用 AI 代写论文 → ❌（学术不端）
- 用 AI 生成虚假评价 → ❌（欺骗消费者）
- 用 AI 批量生成垃圾内容 → ❌（污染信息环境）
- 用 AI 模仿特定作者风格冒充 → ❌（侵权风险）
- 用 AI 生成虚假新闻 → ❌（违法）

## 小结

```
核心原则：
```
