# 商业文案接单

> 从"会用 AI 写"到"靠 AI 写赚钱"，差的只是迈出这一步。

---

| 类型           | 单价            | 难度     | 说明                 |
| -------------- | --------------- | -------- | -------------------- |
| 小红书笔记代写 | 20-80 元/篇     | ⭐       | 最易上手，需求量最大 |

## 二、在哪接单？

### 闲鱼（新手首选）

**优势**：零门槛、自带流量、当天可上架

**操作步骤**：

1. 用支付宝登录闲鱼
2. 发布商品 → 选"技能服务"
3. 标题写清楚：「AI文案代写 小红书笔记 公众号文章 简历优化」
4. 定价：先定 9.9-19.9（引流价）
5. 详情写清楚服务内容和交付标准
6. 用 AI 做几张案例图当主图

**关键**：标题要包含用户会搜的关键词

### 小红书（进阶）

**方式**：发笔记展示你的作品 → 吸引客户私信

**示例笔记**：

- 标题：「用 AI 帮客户写了一周文案，赚了 2000 块」
- 内容：展示作品截图 + 收入截图 + 经验分享
- 效果：自然引流，客单价比闲鱼高 30-50%

### 朋友圈（别忽略）

```
发一条朋友圈：
"最近在用 AI 帮人写文案/做 PPT/优化简历，
有需要的朋友私我，第一单半价体验~"

你的第一个客户，往往就在微信通讯录里。
```

## 三、接单流程

```
客户咨询
  ↓
确认需求（什么类型、字数、用途、截止时间）
  ↓
报价（根据类型和难度）
  ↓
收定金（50% 或全款，小额可全款）
  ↓
用 AI 生成初稿 → 人工润色
  ↓
发给客户确认
  ↓
修改（提前约定修改次数，最多 2 次）
  ↓
收尾款 → 交付
  ↓
满意的话请客户给好评 + 转介绍
```

## 四、定价策略

### 起步阶段（前 10 单）

```
目标：攒好评和案例，不追求利润

定价：
- 小红书笔记：9.9-19.9 元
- 公众号文章：29.9-49.9 元
- 简历优化：19.9-39.9 元
- PPT 内容：29.9-49.9 元
```

### 成长阶段（10-50 单）

```
有了好评和案例后涨价：
- 小红书笔记：39-80 元
- 公众号文章：80-200 元
- 简历优化：50-100 元
- 包月服务：3000-5000 元
```

### 成熟阶段（50 单+）

```
筛选客户，做高客单价：
- 品牌文案：200-500 元
- 电商详情页：300-800 元
- 包月代运营：5000-8000 元
- 知识付费（教别人）：另算
```

## 五、客户沟通模板

### 需求确认

```
你好！请告诉我以下信息：
1. 需要什么类型？（小红书笔记/公众号/简历/其他）
2. 主题/方向是什么？
3. 字数要求？
4. 用途是什么？（发布平台/提交对象）
5. 有没有参考样例？
6. 什么时候要？
```

### 报价话术

```
根据您的需求，报价如下：
- 类型：[XX]
- 字数：[XX]
- 价格：[XX] 元
- 交付时间：[XX] 小时内
- 含 1 次免费修改

确认后我先收 50% 定金开始制作~
```

### 交付话术

```
您好，文案已完成，请查收附件。
如有需要修改的地方，请在 24 小时内告知，
我免费提供 1 次修改服务~
满意的话麻烦给个好评哦，谢谢！
```

## 六、避坑指南

1. **先收钱再做** — 小额（50 元以下）可全款，大额收 50% 定金
2. **约定修改次数** — 最多 2 次，否则无限改稿会亏本
3. **保留聊天记录** — 防止客户赖账
4. **不做违规内容** — 论文代写、虚假宣传等不接
5. **记录每单耗时** — 算清楚你的时薪，低于 30 元/小时的活少接
