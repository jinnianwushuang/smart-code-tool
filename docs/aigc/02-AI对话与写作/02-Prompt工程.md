# Prompt 工程 — 让 AI 听懂你

> AI 的输出质量，80% 取决于你的提示词写得好不好。

---

## 什么是 Prompt？

Prompt = 你输入给 AI 的指令/问题/描述。

```
Prompt 写得好 → AI 输出精准，一次到位
Prompt 写得差 → AI 输出跑偏，反复修改
```

---

## 基础公式

### 万能提示词框架

```
角色 + 任务 + 要求 + 格式 + 示例
```

| 要素 | 说明           | 举例                           |
| ---- | -------------- | ------------------------------ |
| 角色 | 告诉 AI 扮演谁 | "你是一个资深小红书运营专家"   |
| 任务 | 具体要做什么   | "帮我写一篇关于 XX 的种草笔记" |
| 要求 | 具体约束条件   | "500字以内，口语化，带 emoji"  |
| 格式 | 输出格式       | "用标题+正文+标签的格式"       |
| 示例 | 给个参考       | "参考这种风格：..."            |

---

## 实例对比

### ❌ 差的 Prompt

```
帮我写一篇小红书笔记
```

AI 会写出一篇泛泛的、没有针对性的内容。

### ✅ 好的 Prompt

```
你是一个资深小红书美妆博主，粉丝 50 万。

任务：帮我写一篇关于"平价防晒霜推荐"的种草笔记。

要求：
- 字数 300-500 字
- 语气活泼、口语化，像和闺蜜聊天
- 推荐 3 款产品，每款 100 字左右
- 包含使用感受、适合肤质、价格
- 适当使用 emoji 表情
- 结尾加互动引导（问读者用哪款）

格式：
标题（带 emoji）
正文
标签（#防晒 #平价好物 等 5 个）
```

## 进阶技巧

### 1. 分步提示

复杂任务不要一次性说，分步骤来：

```
第一步：帮我分析"职场穿搭"这个赛道在小红书的竞争情况
第二步：根据分析结果，给出 5 个选题方向
第三步：选择第 3 个选题，写一篇完整笔记
```

### 2. 给参考样本

```
以下是我过去写得最好的 3 篇笔记：
[粘贴内容]

请分析我的写作风格，然后用同样的风格写一篇关于 XX 的新笔记。
```

### 3. 负面提示（告诉 AI 不要做什么）

```
写一篇产品介绍文案。

要求：
- 不要用"革命性""颠覆""引领潮流"这类夸张词
- 不要超过 500 字
- 不要用小标题，用自然段落
```

### 4. 迭代优化

AI 第一次输出不满意？不要重新写 Prompt，而是让它改：

```
整体不错，但有以下问题需要修改：
1. 开头太平淡，加一个吸引眼球的钩子
2. 第二段太专业了，改成大白话
3. 结尾太弱，加一个强互动引导
```

## 不同场景的 Prompt 模板

### 自媒体文案

```
你是一个 [平台] 的资深博主，擅长写 [领域] 内容。

请写一篇关于 [主题] 的 [内容类型]。

目标受众：[描述你的受众]
语气风格：[口语化/专业/幽默/温暖]
字数要求：[XXX 字以内]
必须包含：[关键信息点]
不要包含：[不想出现的内容]
```

### 商业文案

```
你是资深商业文案。请为以下产品/服务写文案：

产品/服务：[名称和简介]
目标客户：[画像]
核心卖点：[1-3 个]
竞品差异：[和竞品比有什么优势]
用途：[朋友圈/详情页/广告/落地页]
字数：[XXX 字]
```

### 短视频脚本

```
你是一个短视频编剧，擅长写 [类型] 脚本。

请写一个 [时长] 的短视频脚本：

主题：[XXX]
风格：[搞笑/知识/情感/悬疑]
目标：[涨粉/带货/引流]
平台：[抖音/视频号/小红书]

格式要求：
- 分镜头写
- 每镜头包含：画面描述 + 台词/旁白 + 时长
- 前 3 秒必须有钩子
```

## 常见错误

| 错误         | 后果        | 修正                           |
| ------------ | ----------- | ------------------------------ |
| 太笼统       | 输出泛泛    | 加具体要求（字数、风格、格式） |
| 一次说太多   | AI 遗漏要点 | 分步骤来                       |
| 不给背景     | AI 瞎猜     | 说清楚目标受众和用途           |
| 不给示例     | AI 猜风格   | 贴一个参考样本                 |
| 期望一次完美 | 失望        | 迭代优化，逐步改进             |
