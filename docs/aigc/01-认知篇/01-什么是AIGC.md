# 什么是 AIGC

> AIGC 不是一个工具，而是一整套"用 AI 做内容"的方法论。

---

## 一句话解释

**AIGC = AI Generated Content（AI 生成内容）**

就是让 AI 帮你创造内容，而不是你自己从零开始做。

---

## AIGC 的五大形态

```
AIGC
├── 📝 文本生成 — AI 帮你写
├── 🎨 图像生成 — AI 帮你画
├── 🎬 视频生成 — AI 帮你拍
├── 🎵 音频生成 — AI 帮你做音乐/配音
└── 🧊 3D 生成  — AI 帮你建模（目前还不成熟，本教程暂不涉及）
```

### 1. 文本生成

| 能做什么   | 举例                             |
| ---------- | -------------------------------- |
| 写文章     | 小红书笔记、公众号文章、SEO 文案 |
| 写商业文档 | PPT 大纲、工作总结、简历、方案   |
| 写脚本     | 短视频脚本、口播文案、广告词     |
| 翻译润色   | 中英互译、论文降重、文案改写     |

**主流工具**：DeepSeek（免费）、ChatGPT、Claude、豆包（中文最好）

**你需要做的**：告诉 AI 你要什么 → AI 出初稿 → 你修改润色 → 交付

### 2. 图像生成

| 能做什么 | 举例                               |
| -------- | ---------------------------------- |
| 商业设计 | 电商主图、海报、Logo、详情页       |
| 个人定制 | 头像、写真、表情包、壁纸           |
| 艺术创作 | 插画、漫画、概念设计               |
| 图片处理 | 换背景、抠图、老照片修复、风格转换 |

**主流工具**：Midjourney（最好看）、Flux（最精准，开源）、ComfyUI（工作流，程序员最爱）

**你需要做的**：描述你要什么图 → AI 生成 → 不满意就调参数 → 交付

### 3. 视频生成

| 能做什么   | 举例                          |
| ---------- | ----------------------------- |
| 短视频     | 知识类、情感类、历史类短视频  |
| 商业视频   | 产品广告、电商展示、企业宣传  |
| 数字人口播 | 不用真人出镜，AI 数字人帮你讲 |
| AI 短剧    | AI 生成画面的连续剧情短片     |

**主流工具**：可灵 AI 3.0（国产最强）、Runway Gen-4.5（专业级）、Seedance 3.0（字节系）

> ⚠️ Sora 已于 2026 年 4 月关停，不要再学

**你需要做的**：写脚本 → AI 生成画面素材 → 剪映剪辑 → 配音配乐 → 发布

### 4. 音频生成

| 能做什么 | 举例                           |
| -------- | ------------------------------ |
| 音乐创作 | 完整歌曲（歌词 + 旋律 + 人声） |
| BGM 制作 | 短视频/播客/游戏背景音乐       |
| 配音     | AI 语音合成、有声书朗读        |
| 声音克隆 | 用你的声音 AI 朗读任何文本     |

**主流工具**：Suno v6（最全面）、Udio（音质最好）、ElevenLabs（配音最强）

**你需要做的**：写歌词/描述风格 → AI 生成 → 挑选满意的版本 → 发布/交付

## AIGC 的工作模式

不管哪种形态，核心流程都是一样的：

```
你的创意/需求
    ↓
告诉 AI（写提示词/Prompt）
    ↓
AI 生成初稿
    ↓
你审核、挑选、修改
    ↓
最终成品 → 发布/交付给客户
```

**关键点**：AI 是工具，你是导演。AI 负责"生产"，你负责"决策"和"品控"。

| 形态 | 成熟度     | 能商用吗   | 说明                                  |
| ---- | ---------- | ---------- | ------------------------------------- |

| 3D   | ⭐⭐       | 还不行     | 太早期，暂不推荐                      |

## 学 AIGC 需要技术基础吗？

**不需要**。2026 年的 AIGC 工具已经足够傻瓜化：

- 写文案？会打字就行
- 画图？会描述就行（程序员还会搭 ComfyUI 工作流，这是加分项）
- 做视频？会拖拽时间线就行（剪映比 PR 简单 10 倍）
- 做音乐？会打字描述风格就行

**但程序员有额外优势**：

- ComfyUI 节点工作流 ≈ 可视化编程，上手极快
- 能搭 API 自动化，批量生产效率碾压普通人
- 能做 AI Agent / 工作流定制，这是普通人做不了的高壁垒服务
