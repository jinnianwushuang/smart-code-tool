# 短视频制作 — 从脚本到成片

> 2026 年最大的内容赛道。

---

## 完整流程

```
第 1 步：写脚本（10 分钟）
├── 用 AI 写分镜脚本
├── 每个镜头：画面描述 + 时长 + 旁白
└── 前 3 秒必须有钩子

第 2 步：生成素材（20 分钟）
├── 用可灵/Runway 生成视频片段
├── 或用即梦生成图片 → 图生视频
└── 每个镜头生成 2-3 个备选

第 3 步：剪辑（20 分钟）
├── 导入剪映
├── 按脚本顺序排列
├── 加转场、特效
└── 调整节奏

第 4 步：配音配乐（10 分钟）
├── 剪映 AI 配音（免费）
├── 或自己录音
├── 加 BGM（剪映自带曲库）
└── 加字幕（自动识别）

第 5 步：导出发布（5 分钟）
├── 导出 1080p
├── 写标题和描述
├── 加话题标签
└── 发布到各平台
```

**总耗时**：约 1 小时/条（1-3 分钟短视频）

---

## 脚本模板

```
视频标题：[吸引人的标题]
时长：[60秒]
平台：[抖音/视频号/小红书]

镜头 1（0-3秒）— 钩子
画面：[描述]
旁白："[台词]"

镜头 2（3-15秒）— 引入
画面：[描述]
旁白："[台词]"

镜头 3-5（15-50秒）— 正文
画面：[描述]
旁白："[台词]"

镜头 6（50-60秒）— 结尾
画面：[描述]
旁白："[总结 + 引导互动]"
```

## 变现方式

| 方式       | 说明             | 收入预期                |
| ---------- | ---------------- | ----------------------- |
| 流量分成   | 平台播放量分成   | 百万播放 ≈ 2000 元      |
| 商单广告   | 品牌合作推广     | 1 万粉 ≈ 500-2000 元/条 |
| 带货       | 视频挂商品链接   | 看品类和销量            |
| 代制作     | 帮客户做短视频   | 100-500 元/条           |
| 数字人口播 | 批量生产口播视频 | 50-200 元/条            |
