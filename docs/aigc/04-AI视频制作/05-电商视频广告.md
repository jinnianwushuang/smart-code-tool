# 电商视频广告

> 电商商家最大的视频需求：产品广告批量制作。

---

## 需求场景

| 类型          | 说明             | 单价                |
| ------------- | ---------------- | ------------------- |
| 产品展示视频  | 360°展示产品外观 | 50-200 元/条        |
| 使用场景视频  | 展示产品使用过程 | 100-300 元/条       |
| 开箱视频      | 模拟开箱体验     | 100-300 元/条       |
| 对比视频      | 产品前后对比     | 100-500 元/条       |
| 批量 SKU 视频 | 多产品批量生成   | 30-80 元/条（量大） |

---

## 制作流程

```
1. 客户提供产品图/白底图
2. 用 ComfyUI 生成场景背景
3. 用可灵生成产品展示视频
4. 剪映加文字、价格、BGM
5. 批量输出（程序员可自动化）
```

---

## 程序员优势

```javascript
// 批量生成 50 个产品视频
for (const product of products) {
  const scene = await generateScene(product.image, product.category)
  const video = await generateVideo(scene, {
    duration: 15,
    camera: 'rotate',
    text: product.name,
  })
  await saveVideo(video, `./output/${product.sku}.mp4`)
}
```
