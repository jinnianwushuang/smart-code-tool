## 怎么选？

## 视频制作完整工作流

```
脚本 → 素材生成 → 剪辑 → 配音配乐 → 字幕 → 发布

工具链：
├── 脚本：DeepSeek/豆包
├── 素材：即梦 AI / 可灵 4.0 / 商汤 Seko / 海螺 AI
├── 剪辑：剪映（最简单）
├── 配音：讯飞配音 / ElevenLabs / 魔音工坊
├── 字幕：剪映自动识别
└── 发布：各平台
```
