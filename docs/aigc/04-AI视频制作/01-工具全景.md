## 视频制作完整工作流

```
脚本 → 素材生成 → 剪辑 → 配音配乐 → 字幕 → 发布

工具链：
├── 脚本：DeepSeek/豆包
├── 素材：可灵/Runway/Seedance
├── 剪辑：剪映（最简单）
├── 配音：剪映自带/ElevenLabs
├── 字幕：剪映自动识别
└── 发布：各平台
```
