## 三大阵营

```
AI 绘画工具分四大派系：

1. Midjourney 派 — “我要好看”
   优势：出图质感最好，v7 画质再升级，短提示词就能出大片
   劣势：不开源，每月 $10-60

2. Nano Banana 派 — “我要智能”
   优势：文字渲染+4K+多参考图融合，Google 最新
   劣势：需要理解模型版本差异

3. Flux/SD 派 — “我要可控”
   优势：开源免费，精准控制，可本地部署
   劣势：需要技术环境，学习曲线陡

4. 即梦/造点 派 — “我要方便”
   优势：在线使用，生图+生视频一体
   劣势：精度和可控性不如前两者
```

## Midjourney 快速入门

### 注册

1. 访问 midjourney.com
2. 订阅计划（基础版 $10/月）
3. 在网页端直接使用

### 基本用法

```
在输入框写提示词：
"A cute cat sitting on a windowsill, sunset light, watercolor style"

MJ v7 会自动生成 4 张图供你选择
```

### 提示词基础

```
公式：主体 + 环境 + 风格 + 质量词

主体：a beautiful woman / a product shot / a logo
环境：in a cafe / on white background / in a forest
风格：watercolor / oil painting / photography / 3D render
质量：masterpiece / best quality / 8K / highly detailed
```

## ComfyUI 快速入门（程序员专场）

### 为什么程序员应该学 ComfyUI

- 节点式工作流 = 可视化编程
- 可以导出/导入 JSON 工作流
- 支持 API 调用，批量自动化
- 社区有海量现成工作流可复用

### 核心概念

| 概念               | 说明                     | 前端类比      |
| ------------------ | ------------------------ | ------------- |
| 节点 (Node)        | 一个处理单元             | 一个函数/组件 |
| 连线 (Link)        | 节点间的数据流           | Props 传递    |
| 模型 (Checkpoint)  | AI 模型文件              | npm 依赖包    |
| 提示词 (CLIP Text) | 描述你要生成什么         | 函数参数      |
| 采样器 (KSampler)  | 生成图片的核心引擎       | 渲染引擎      |
| VAE                | 解码器，把潜空间转为图片 | 编译器        |

### 最小工作流（5 个节点）

```
Load Checkpoint → CLIP Text Encode (正/负提示词)
                        ↓
                   KSampler → VAE Decode → Save Image
```

### 学习资源

- ComfyUI 官方文档：comfy.org
- 社区工作流：comfyworkflows.com
- B站搜索"ComfyUI 教程"

## 零成本方案

```
全部开源免费：
├── Flux 2 Dev（模型）— 本地运行
├── ComfyUI（界面）— 本地运行
└── ControlNet（控制）— 本地运行

要求：
- 显卡：NVIDIA GPU，显存 ≥ 8GB（推荐 12GB+）
- 内存：≥ 16GB
- 硬盘：≥ 50GB 空闲（模型文件很大）
```

没有好显卡？用云端：

- ComfyUI Cloud（官方云服务）
- Google Colab（免费 GPU）
- 阿里云计算巢（按量付费）
