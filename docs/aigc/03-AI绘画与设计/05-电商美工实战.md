## 工作流设计

### 产品主图工作流

```
输入：产品照片（手机拍即可）
1. 自动抠图（Segment Anything）
2. 背景替换（白色/浅色/场景）
3. 光影调整
4. 高清放大到 3000x3000
5. 批量处理 50+ SKU
输出：电商主图套装
```

### 产品场景图工作流

```
输入：产品白底图 + 场景描述
1. 抠图提取产品
2. 生成场景背景
3. 产品放入场景
4. 光影融合
5. 细节修复
输出：产品在场景中的效果图
```
