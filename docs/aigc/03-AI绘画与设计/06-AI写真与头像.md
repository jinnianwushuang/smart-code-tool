## 市场概况

| 类型            | 单价         | 需求量 | 说明         |

## 头像风格参考

```
热门头像风格：
├── 动漫/二次元风 — 年轻用户最爱
├── 写实/商务风 — 求职、社交
├── 油画/艺术风 — 文艺范
├── 赛博朋克风 — 潮流感
├── 黏土/3D 风 — 可爱萌系
├── 像素风 — 复古游戏感
└── 水彩风 — 温柔清新
```

---

## 接单流程

```
1. 客户提供 1-3 张照片
2. 确认风格（给客户看风格样本）
3. 用 AI 生成 5-10 张候选
4. 客户挑选满意的
5. 精修交付
```
