# 商业接单全流程

> 从 0 到第一笔收入的完整路径。

---

## 第一步：准备作品集（Day 1-2）

```
用 AI 生成 10-20 个作品：
├── 3-5 个头像作品
├── 3-5 个电商产品图
├── 3-5 个海报/封面设计
└── 2-3 个风格化作品

要求：
- 选最好的，不要凑数
- 标注"AI 辅助创作"
- 保存高清原图
```

## 第二步：上架闲鱼（Day 2-3）

```
操作步骤：
1. 发布 3-5 个商品（不同品类）
2. 标题包含关键词：AI头像/AI绘画/AI设计/AI产品图
3. 定价 9.9-19.9（引流价）
4. 主图用你的作品集
5. 详情写清楚服务内容和交付标准
```

## 第三步：同步发小红书（Day 3-5）

```
发 3 篇笔记：
1. 作品展示（"用 AI 画了一套头像"）
2. 过程分享（"AI 绘画幕后"）
3. 接单信息（"AI 绘画接单中，首单优惠"）
```

## 第四步：接第一单（Day 5-7）

```
客户咨询 → 确认需求 → 收定金 → 制作 → 交付 → 收好评
```

## 第五步：涨价与升级（Day 7+）

```
攒够 10 个好评后：
- 价格翻倍
- 增加高客单价品类
- 开始做包月服务
```

---

## 定价策略总结

| 阶段     | 目标     | 定价        |
| -------- | -------- | ----------- |
| 前 10 单 | 攒好评   | 9.9-19.9 元 |
| 10-50 单 | 稳定收入 | 39-99 元    |
| 50 单+   | 筛选客户 | 99-299 元   |
| 100 单+  | 高端定制 | 299-999 元  |
