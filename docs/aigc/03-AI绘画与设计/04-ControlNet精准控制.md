# ControlNet 精准控制

> 告别"抽卡"模式，让 AI 按照你的要求精确出图。

---

## 什么是 ControlNet？

没有 ControlNet：你写提示词 → AI 随机生成 → 看运气（"抽卡"）

有了 ControlNet：你提供参考图 + 控制条件 → AI 精确生成

---

## ControlNet 类型速查

| 类型      | 控制什么    | 典型应用          |
| --------- | ----------- | ----------------- |
| Canny     | 边缘轮廓    | 产品图、Logo 还原 |
| Depth     | 深度信息    | 建筑、室内场景    |
| OpenPose  | 人物姿态    | 写真、电商模特    |
| Scribble  | 草图 → 成品 | 概念设计          |
| Lineart   | 线稿 → 上色 | 漫画、插画        |
| Style     | 风格迁移    | 照片转油画        |
| IPAdapter | 参考图风格  | 保持角色一致性    |

## 实战场景

### 场景 1：电商产品换背景

```
输入：产品白底图 + 想要的场景描述
ControlNet：Canny（保持产品轮廓不变）
输出：产品在场景中的效果图
```

### 场景 2：人物写真

```
输入：一张面部照片 + 想要的姿态
ControlNet：OpenPose（控制身体姿态）+ IPAdapter（保持面部）
输出：不同姿态的写真照片
```

### 场景 3：室内设计

```
输入：房间照片 + 想要的风格
ControlNet：Depth（保持空间结构）
输出：不同装修风格的效果图
```

### 场景 4：草图变成品

```
输入：手绘草图
ControlNet：Scribble（识别草图内容）
输出：精细的成品图
```

## 使用要点

### 权重设置

```
ControlNet weight: 0.5-1.0
- 太高：生成图过于死板，失去创意
- 太低：控制不住，跑偏
- 建议从 0.7 开始调
```

### 多 ControlNet 叠加

```
可以同时使用多个 ControlNet：
- OpenPose (0.6) + IPAdapter (0.5) = 控制姿态 + 保持面部

注意：
- 每个 weight ≤ 0.8
- 总和 ≤ 2.0
- 错开 start_percent 和 end_percent
```
