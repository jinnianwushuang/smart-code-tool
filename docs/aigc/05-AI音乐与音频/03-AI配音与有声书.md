## 有声书制作

```
流程：
1. 获取文本内容（公版书/客户稿件）
2. 用 ElevenLabs 生成配音
3. 分段导出
4. 剪映做后期（加 BGM、音效）
5. 导出成品

定价：
- 100-500 元/万字
- 长篇可谈包月
```

---

## 声音克隆

```
步骤（ElevenLabs）：
1. 录制 1-5 分钟清晰语音
2. 上传到 ElevenLabs
3. AI 克隆你的声音
4. 输入任何文字 → 用你的声音朗读

用途：
- 批量配音（不用每次自己录）
- 多语言配音（你的声音说英语/日语）
- 有声书批量制作
```
