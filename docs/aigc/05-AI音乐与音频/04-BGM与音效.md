# BGM 与音效

> 短视频/播客/游戏都需要 BGM，AI 可以批量做。

---

## 用 Suno 做 BGM

```
提示词模板：
"[风格] background music, [情绪], [节奏], no vocals, [时长]"

示例：
"lo-fi hip hop background music, chill and relaxing,
slow tempo, no vocals, 2 minutes"

"upbeat corporate background music, motivational,
energetic, no vocals, 90 seconds"
```

## 用 Suno Speech 做播客 intro

```
输入：
"欢迎来到 XX 播客，每周三更新，
带你了解最新的 AI 工具和使用技巧"

描述：
"male voice, warm and friendly, with upbeat lo-fi BGM"

→ 一次性生成语音 + BGM 融合音轨
```
