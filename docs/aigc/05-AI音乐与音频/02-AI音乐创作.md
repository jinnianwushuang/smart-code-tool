# AI 音乐创作 — 从零做一首歌

> 不需要懂乐理，只需要有想法。

---

## 用 Suno v6 创作完整歌曲

### 方式 1：文字描述

```
步骤：
1. 打开 suno.com
2. 选择 v6 模型
3. 输入描述：
   "一首关于程序员转行的中文流行歌曲，
    略带忧伤但充满希望，
    80年代合成器风格，男声"
4. 点击 Create
5. 从生成的 2 个版本中选满意的
```

### 方式 2：自己写歌词

```
步骤：
1. 切换到 Custom 模式
2. 输入自己的歌词（可用 AI 帮写）
3. 选择风格：Pop / Rock / Electronic / R&B...
4. 生成
```

### 方式 3：多模态输入

```
步骤：
1. 上传一张图片/一段视频/一段哼唱
2. Suno 会根据输入的氛围生成音乐
3. 适合做 BGM、氛围音乐
```

---

## 精准编辑

```
对已生成的歌曲做局部修改：
1. 选中需要修改的片段
2. 修改该段的歌词/风格
3. 只重新生成选中部分
4. 其他部分保持不变
```
