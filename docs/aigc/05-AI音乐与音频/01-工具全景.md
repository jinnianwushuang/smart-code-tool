## Suno v6 详解

### 三大模型

| 模型    | 特点           | 适合               |
| ------- | -------------- | ------------------ |
| v6      | 目标明确时使用 | 已知风格/人声/节奏 |
| v6-wild | 探索意外组合   | 寻找灵感           |
| v6-mini | 轻量免费       | 免费用户体验       |

### 核心能力

- **Cover 功能**：上传音频/视频，改变风格/人声/节奏
- **精准编辑**：局部修改，不用重新生成整首
- **续写功能**：从任意位置继续创作
- **音轨分离**：提取人声/乐器单独处理
- **50+ 语言**：中文/英文/日语等
