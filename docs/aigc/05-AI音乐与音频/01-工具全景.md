## Suno v6 详解

### 三大模型

| 模型    | 特点           | 适合               |
| ------- | -------------- | ------------------ |
| v6      | 目标明确时使用 | 已知风格/人声/节奏 |
| v6-wild | 探索意外组合   | 寻找灵感           |
| v6-mini | 轻量免费       | 免费用户体验       |

### 核心能力

- **多模态输入**：图片/视频/语音备忘录 → 音乐
- **精准编辑**：局部修改，不用重新生成整首
- **Speech 功能**：端到端生成语音+BGM 融合音轨
- **50+ 语言**：中文/英文/日语等

## 变现方式

| 方式         | 说明                         | 收入            |
| ------------ | ---------------------------- | --------------- |
| 定制歌曲     | 帮客户写歌（生日/表白/企业） | 50-200 元/首    |
| BGM 定制     | 短视频/播客背景音乐          | 30-100 元/首    |
| 有声书制作   | AI 配音+后期                 | 100-500 元/万字 |
| 音乐平台分发 | 上传到 Spotify/Apple Music   | 被动收入        |
| 配音服务     | 商业配音、广告配音           | 50-200 元/分钟  |
