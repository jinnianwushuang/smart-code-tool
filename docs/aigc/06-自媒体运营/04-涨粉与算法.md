## 各平台算法核心逻辑

| 平台   | 核心指标                 | 推荐逻辑                  |
| ------ | ------------------------ | ------------------------- |
| 小红书 | 收藏率 > 点赞率 > 评论率 | 互动率高 → 推更多流量     |
| 抖音   | 完播率 > 互动率          | 看完率高 → 进入更大流量池 |
| B站    | 三连率（点赞+投币+收藏） | 三连多 → 推荐到首页       |
| 视频号 | 社交推荐 > 算法推荐      | 朋友点赞 → 朋友的朋友看到 |

## 涨粉策略

### 通用策略

1. **垂直深耕** — 只做一个领域，不要什么都发
2. **持续输出** — 至少每周 3 篇，坚持 3 个月
3. **标题决定生死** — 80% 的爆款靠标题
4. **前 3 秒定生死**（视频）— 必须有钩子
5. **引导互动** — 结尾问问题，引导评论

### 小红书专项

- 封面图要好看（决定点击率）
- 标题带数字和痛点
- 正文加 emoji，分段清晰
- 标签 5-10 个
- 每天 1-2 篇，固定时间发布

### 抖音专项

- 前 3 秒必须有钩子
- 视频 15-60 秒最佳
- 完播率 > 一切
- 热门 BGM 加分
- 发布时间：12:00 / 18:00 / 21:00
