# 变现模型

> 粉丝不等于收入，但有粉丝就有更多变现方式。

---

## 变现方式

| 方式         | 需要多少粉      | 收入预期 | 说明                    |
| ------------ | --------------- | -------- | ----------------------- |
| 平台流量分成 | 0（有播放就有） | 低       | 百万播放 ≈ 2000 元      |
| 广告合作     | 5000+           | 中       | 1 万粉 ≈ 500-2000 元/条 |
| 带货         | 1000+           | 高       | 佣金模式                |
| 知识付费     | 1000+           | 很高     | 课程/资料包             |
| 引流到私域   | 不限            | 高       | 卖服务/产品             |
| 接单         | 不限            | 中       | 展示作品 → 客户找来     |

---

## 推荐变现组合

```
起步期（0-1000 粉）：
├── 接单（展示作品引流）
└── 平台流量分成

成长期（1000-10000 粉）：
├── 接单
├── 广告合作
└── 知识付费（资料包/小课程）

成熟期（10000+ 粉）：
├── 广告合作（主要收入）
├── 知识付费（课程/社群）
├── 带货
└── 私域转化
```
