# 平台选择策略

> 不同平台，不同玩法。选对平台事半功倍。

---

## 主流平台对比

| 平台   | 内容形式    | 用户画像        | 变现方式           | 适合       |
| ------ | ----------- | --------------- | ------------------ | ---------- |
| 小红书 | 图文+短视频 | 女性为主，18-35 | 广告/带货/引流     | 种草、教程 |
| 抖音   | 短视频      | 全年龄          | 流量分成/带货/直播 | 娱乐、知识 |
| B站    | 中长视频    | 年轻人，Z世代   | 流量分成/广告      | 深度内容   |
| 视频号 | 短视频      | 30+，微信生态   | 社交裂变/带货      | 中年用户   |
| 公众号 | 长文        | 全年龄          | 广告/知识付费      | 深度文章   |

---

## 推荐策略

```
起步期：选 1 个平台深耕
├── AIGC 教程类 → 小红书（图文教程）
├── AI 工具测评 → B站（视频测评）
├── AI 赚钱经验 → 抖音/视频号（短视频）
└── 深度技术 → 公众号（长文）

成长期：扩展到 2-3 个平台
├── 一次创作，多平台分发
└── 不同平台做适配调整
```
