# 多平台分发

> 一次创作，多平台发布，效率最大化。

---

## 分发工作流

```
原始内容（一篇长文/一条视频）
    ↓
适配各平台格式
├── 小红书：图文笔记（封面图+正文+标签）
├── 抖音：15-60 秒短视频
├── B站：3-10 分钟中长视频
├── 视频号：1 分钟短视频
├── 公众号：长文版
└── 知乎：问答版
```

---

## 内容适配要点

| 平台   | 格式要求               | 注意事项         |
| ------ | ---------------------- | ---------------- |
| 小红书 | 3:4 封面图，300-800 字 | 加 emoji，加标签 |
| 抖音   | 9:16 竖屏，15-60 秒    | 前 3 秒钩子      |
| B站    | 16:9 横屏，3-10 分钟   | 加片头片尾       |
| 视频号 | 9:16 或 16:9           | 利用微信社交链   |
| 公众号 | 长文，配图             | 深度内容         |

---

## 自动化工具

- 剪映：一次剪辑，多尺寸导出
- 蚁小二：多平台一键分发
- 程序员可以自己写脚本自动发布
