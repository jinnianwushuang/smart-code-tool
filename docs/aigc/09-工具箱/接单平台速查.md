## 推荐路径

```
新手起步 → 闲鱼（零门槛，最快出单）
有案例后 → 小红书（发内容引流）
AI 漫剧 → 泡漫接单广场（保底+分成）
英语好   → Fiverr（海外客单价 3-5 倍）
微信生态 → 腾讯企鹅微单（2026.10 新上线）
长期经营 → 自媒体 + 私域（客户主动找来）
```

---

## 接单避坑

1. 任何让你先交钱 → 骗子
2. 先收定金再做
3. 约定修改次数（最多 2 次）
4. 保留聊天记录
5. 不接违规内容
