# 接单平台速查

> 所有接单平台的一页纸速查。

---

| 平台     | 门槛     | 新手友好   | 客单价    | 核心特点           |
| -------- | -------- | ---------- | --------- | ------------------ |
| 闲鱼     | 零       | ⭐⭐⭐⭐⭐ | 20-200元  | 搜索流量，当天出单 |
| 小红书   | 中       | ⭐⭐⭐⭐   | 100-500元 | 展示引流，客单价高 |
| 猪八戒   | 低       | ⭐⭐       | 中等      | 竞标制，新手难     |
| Fiverr   | 中(英语) | ⭐⭐⭐     | $20-300   | 海外高客单价       |
| 豆瓣小组 | 低       | ⭐⭐⭐     | 低        | 精准社区           |
| 甜薪工场 | 中       | ⭐⭐⭐     | 中高      | 远程工作           |

---

## 推荐路径

```
新手起步 → 闲鱼（零门槛，最快出单）
有案例后 → 小红书（发内容引流）
英语好   → Fiverr（海外客单价 3-5 倍）
长期经营 → 自媒体 + 私域（客户主动找来）
```

---

## 接单避坑

1. 任何让你先交钱 → 骗子
2. 先收定金再做
3. 约定修改次数（最多 2 次）
4. 保留聊天记录
5. 不接违规内容
