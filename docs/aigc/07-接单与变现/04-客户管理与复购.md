# 客户管理与复购

> 维护一个老客户的成本，是开发新客户的 1/5。

---

## 客户管理要点

1. **建立客户档案** — 记录每个客户的需求、偏好、历史订单
2. **及时响应** — 24 小时内回复所有咨询
3. **超预期交付** — 比承诺的多给一点
4. **主动跟进** — 交付后 3 天问满意度
5. **请求转介绍** — 满意的话请推荐朋友

---

## 复购策略

| 策略     | 说明                    |
| -------- | ----------------------- |
| 包月服务 | "每月 X 篇，优惠价 XXX" |
| 会员价   | "老客户 8 折"           |
| 增值服务 | "加 XX 元升级 XX"       |
| 节日关怀 | 节假日发个问候          |
