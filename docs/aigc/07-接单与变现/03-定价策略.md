# 定价策略

> 从低价引流到价值定价的进阶路径。

---

## 涨价节奏

```
第 1 阶段（前 10 单）：9.9-19.9 元
├── 目标：攒好评和案例
└── 心态：不赚钱没关系，攒口碑

第 2 阶段（10-50 单）：39-99 元
├── 目标：稳定收入
└── 有好评背书，可以涨价

第 3 阶段（50-100 单）：99-299 元
├── 目标：筛选客户
└── 做高客单价，减少单量

第 4 阶段（100 单+）：299-999 元
├── 目标：高端定制
└── 品牌溢价，卖解决方案
```

---

## 定价心理学

| 策略     | 说明                     |
| -------- | ------------------------ |
| 尾数定价 | 99 比 100 感觉便宜很多   |
| 锚定效应 | 先展示高价，再展示实际价 |
| 套餐定价 | 基础版/标准版/高级版     |
| 限时优惠 | "本周特价"制造紧迫感     |
