# 从零到第一单 — 7 天实操指南

> 别想太多，7 天内收到第一笔钱。

---

## Day 1：选方向

```
从以下选一个（最适合新手的）：
├── AI 头像定制（最简单）
├── AI 文案代写（需求最大）
└── AI PPT 制作（刚需）
```

## Day 2：做案例

```
用 AI 做 5-10 个作品：
├── 头像：做 5 个不同风格
├── 文案：写 3 篇小红书笔记
└── PPT：做 2 套模板
```

## Day 3：上架

```
闲鱼上架：
├── 发布 3 个商品
├── 标题含关键词
├── 定价 9.9-19.9
├── 主图用案例作品
└── 详情写清服务内容
```

## Day 4-5：推广

```
同步推广：
├── 小红书发 2 篇笔记（展示作品）
├── 朋友圈发 1 条（告知朋友）
└── 微信群发 1 条（精准触达）
```

## Day 6-7：交付

```
接到第一单：
├── 确认需求
├── 制作交付
├── 客户满意 → 请给好评
└── 不满意 → 免费修改 1 次
```
