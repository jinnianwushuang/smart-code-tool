# Vue 标准化装配架构 — 架构概述

## 简介

Vue 标准化装配架构是一套可插拔、模块化的 Vue.js 页面架构，强调模块化、可组合性和清晰的关注点分离。它通过统一的 `payload` 上下文、动态模块扫描和 `useContextAssembler` 装配器，标准化页面开发流程，同时保持高度的可扩展性。

该架构提供两种模板：

- **多例模板**（`src/standardization/multiton-template/`）— 每实例独立状态
- **单例模板**（`src/standardization/singleton-template/`）— 跨实例共享状态，额外提供 `expose.js` 和 `api-request/`

## 核心架构原则

### 1. **可插拔模块系统**

每个组件（状态、生命周期、效果、事件、API请求）都是独立可加载和可组合的。模块通过Vite的`import.meta.glob()`自动发现，并在运行时组装。

### 2. **关注点分离**

该模板分离了：

- **状态管理**（单例、多例、计算属性）
- **生命周期钩子**（Vue 3生命周期事件）
- **事件处理**（发射、事件管道、用户交互）
- **副作用**（DOM、观察器、监听器、定时器、事件发射器）
- **API通信**（数据获取和转换）
- **组件组合**（具有可重用逻辑的UI组件）

### 3. **装配器模式**

架构的核心是**装配器模式**，它：

- 扫描并自动发现模块
- 将它们组合成内聚的单元
- 通过`useContextAssembler`可组合函数提供注入
- 消除手动模块导入和注册

## 目录结构

```
src/standardization/multiton-template/        # 多例模板（单例模板结构类似）
├── index.vue                 # 主页面组件
├── assembler/                # 装配器
│   └── assembler.js          # 主装配器（import.meta.glob 自动扫描）
├── state/                    # 状态管理
│   ├── config.js             # 配置选项
│   ├── singleton.js          # 单例状态聚合（仅单例模板）
│   ├── multiton.js           # 多例状态
│   ├── computed.js           # 计算属性
│   └── singleton/            # 单例状态模块
│       ├── table.js          # 表格相关状态
│       ├── dialog.js         # 对话框相关状态
│       └── other.js          # 其他共享状态
├── module/                   # 业务逻辑模块
│   ├── lifecycle/            # 6个生命周期钩子
│   ├── emit/                 # 事件发射器
│   ├── exposed-method/       # 暴露方法
│   ├── event-pipeline/       # 事件管道系统
│   ├── effect/               # 6种副作用清理（dom/listener/watcher/timer/mitter/other）
│   └── other-method/         # 实用方法
├── component/                # UI组件（可嵌套装配）
├── css/                      # 样式
└── （单例模板额外提供）
    ├── assembler/expose.js   # 对下游组件声明提供的状态和事件通道
    └── api-request/          # API请求处理
        └── module/handle_init_table_data.js
```

## 关键技术栈

- **Vue 3** — 组合式 API
- **Vite** — `import.meta.glob()` 动态模块扫描与自动装配
- **响应式系统** — `ref()`、`computed()`、`watch()`
- **Mitt** — 跨组件通信的自定义事件发射器
- **payload 上下文** — 统一上下文对象在模块间传递
- **useContextAssembler()** — 组合式注入函数

## 执行流程

### 初始化阶段

1. 用户打开页面 → `index.vue` 加载
2. `all_atoms_assembler()` 通过 `import.meta.glob()` 扫描 `module/**/*.js` 和 `state/*.js`
3. `atoms_assembler()` 验证、分类、组合模块
4. `useContextAssembler(base_payload, all_atoms_assembler())` 注入上下文
5. 生命周期钩子自动调用（`lifecycle_onBeforeMount` → `lifecycle_onMounted`）
6. 副作用清理函数注册

### 运行时阶段

1. 组件使用装配器的 payload 上下文渲染
2. 用户交互触发事件管道（`ALL_EVENT_PIPELINE`）或发射函数
3. 事件管道处理程序更新状态或触发 API 调用
4. API 调用修改单例/多例状态
5. Vue 响应式传播变化到 UI

### 清理阶段

1. 组件卸载前 → `lifecycle_onBeforeUnmount` 调用
2. 6 种副作用自动清理（DOM、监听器、观察器、定时器、Mitter、其他）
3. 单例状态为下次初始化保留（调用 `init_singleton()` 重置）
4. 资源释放

## 此架构的优势

| 特性           | 优势                               |
| -------------- | ---------------------------------- |
| **模块化设计** | 易于理解、测试和维护单个模块       |
| **自动发现**   | 无需手动注册 - 模块自动发现        |
| **可插拔**     | 添加/删除模块而不改变核心代码      |
| **上下文统一** | payload 上下文在所有模块间统一传递 |
| **可扩展**     | 成长中的项目组织一致               |
| **可重用**     | 组件和逻辑可在页面间共享           |
| **可测试**     | 具有依赖注入的纯函数               |
| **可配置**     | 状态中的集中配置                   |

## 入门指南

该架构提供两种模板：

1. **多例模板**（`src/standardization/multiton-template/`）— 每个组件实例拥有独立状态，适合多个同类组件并排场景
2. **单例模板**（`src/standardization/singleton-template/`）— 跨实例共享状态，额外提供 `expose.js`（对下游声明接口）和 `api-request/`（标准请求流程），适合标准 CRUD 管理页

详细演进过程请参阅 [LV1-LV5 架构演进](/architecture-document/vue/standardized-template-cn/architecture-evolution-cn)。
