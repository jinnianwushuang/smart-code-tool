# 任务：代码检查

> 检查代码是否符合架构规范和 React 19 最佳实践。

## 执行步骤

### 1. 确定检查范围

```
1. 确认检查目标（整个页面 / 指定目录 / 指定文件）
2. 读取目标文件
```

### 2. 执行检查（按维度逐项检查）

#### 2.1 React Compiler 兼容性

```
- 是否有手写 useMemo / useCallback
- 是否有使用 forwardRef
- 是否有使用 defaultProps / propTypes
- 是否有 class 组件
```

#### 2.2 Hook 规则

```
- 是否有条件/循环中调用 Hook
- useEffect 是否有清理函数
- 状态更新是否使用函数式更新
- 依赖数组是否完整
```

#### 2.3 组件规范

```
- 组件是否单一职责
- 是否在组件内定义子组件
- 组件文件是否超过 200 行
- 复杂逻辑是否抽取到 Hook
```

#### 2.4 命名规范

```
- 组件文件 PascalCase.jsx
- Hook 文件 kebab-case.js + use- 前缀
- 变量 camelCase
- 事件处理 handle 前缀
```

#### 2.5 CSS 规范

```
- 是否优先使用 UI 框架组件
- 是否使用全局 CSS 变量
- 是否有不通用的自定义 CSS
```

#### 2.6 代码量

```
- 单组件文件 ≤ 200 行
- 单 Hook 文件 ≤ 300 行
- 单函数 ≤ 50 行
- 注释比例 ≥ 10%
```

### 3. 生成检查报告

```
1. 按维度列出发现的问题
2. 每个问题标注严重程度（错误 / 警告 / 建议）
3. 给出修复建议
4. 保存到 config.md 中配置的报告目录
```

## 完成标准

- [ ] 所有维度已检查
- [ ] 检查报告已生成
- [ ] 每个问题有修复建议
- [ ] 执行报告已输出
