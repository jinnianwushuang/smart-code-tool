# 任务：重构

> 将现有代码改造为符合架构规范的结构。

## 执行步骤

### 1. 分析现有代码

```
1. 读取目标文件/目录，理解现有实现
2. 识别不符合架构规范的部分
3. 制定重构计划（列出需要变更的文件和目标结构）
4. 如有歧义，触发「存疑即问」
```

### 2. 制定重构方案

```
1. 列出当前问题（如：class 组件、逻辑耦合、状态混乱等）
2. 列出目标结构（符合架构规范的目录和文件）
3. 确定重构顺序（从底层到顶层，避免中间态破坏）
4. 输出重构方案供使用者确认
```

### 3. 执行重构

```
1. 将 class 组件改为函数组件（如需要）
2. 将内联逻辑抽取到自定义 Hook
3. 拆分过大的组件文件
4. 移除 useMemo/useCallback/forwardRef（React Compiler 自动处理）
5. 统一命名规范
6. 更新 CSS 使用框架组件和全局变量
```

### 4. 验证重构结果

```
1. 执行 common-steps.md 中的步骤 D（静态分析自检）
2. 确认功能等价（重构前后行为一致）
3. 确认无引入新的 lint 警告
```

### 5. 输出报告

```
→ 执行 common-steps.md 中的步骤 E（输出执行报告）
→ 额外列出：重构前后对比、移除的反模式清单
```

## 完成标准

- [ ] 所有代码符合架构规范
- [ ] 无 class 组件、无手写 useMemo/useCallback/forwardRef
- [ ] 组件和 Hook 行数在约束范围内
- [ ] 功能等价，未引入新 bug
- [ ] 注释比例达标
