# 门禁检查 — 前置条件

> AI 在执行任何任务前，必须先通过以下检查。任一不通过则停止，告知缺失项。

## 1. 配置完整性检查

- [ ] config.md 已填写且关键路径配置不为空
- [ ] `pages_root_path` 已配置
- [ ] `shared_components_path` 已配置
- [ ] `ui_framework` 已配置
- [ ] `state_management` 已配置

## 2. 核心文件存在性检查

- [ ] 页面入口文件存在：`pages/<页面名>/index.jsx`
- [ ] 页面 Hook 存在：`pages/<页面名>/hooks/`
- [ ] API 客户端文件存在（配置路径）

## 3. 任务信息检查

- [ ] 任务类型已明确（新需求 / 重构 / 迭代 / 修复 / 代码检查）
- [ ] 目标文件或目录已指定
- [ ] 需求描述足够清晰，无歧义

## 4. 依赖检查

- [ ] React 相关依赖已安装
- [ ] UI 框架依赖已安装（根据 config.md 中的配置）
- [ ] 构建工具可用（Vite / Next.js 等）

## 检查失败处理

- 配置缺失 → 提示使用者补充 config.md
- 文件不存在 → 提示使用者确认路径或先创建基础文件
- 信息不足 → 触发「存疑即问」，向使用者提问
- 依赖缺失 → 提示使用者安装依赖
