# 任务：需求迭代

> 在已有页面基础上增加或修改功能。

## 执行步骤

### 1. 分析变更范围

```
1. 读取目标页面现有代码，理解现有结构
2. 确定需要修改的文件（Hook / 组件 / Action）
3. 评估变更对现有功能的影响
4. 如有歧义，触发「存疑即问」
```

### 2. 修改页面 Hook

```
1. 在现有 Hook 中添加新状态/方法（参照 hooks-reference.md）
2. 新增事件处理函数
3. 确保不破坏现有功能
4. 如果 Hook 过大，拆分为多个子 Hook
```

### 3. 修改/新增组件

```
1. 修改现有组件的 props 和渲染逻辑
2. 或创建新组件（参照 common-steps.md 步骤 C）
3. 更新页面入口组件的 props 传递
```

### 4. 验证变更

```
1. 执行 common-steps.md 中的步骤 D（静态分析自检）
2. 确认新增功能与现有功能不冲突
```

### 5. 输出报告

```
→ 执行 common-steps.md 中的步骤 E（输出执行报告）
→ 额外列出：变更影响范围、是否有破坏性变更
```

## 完成标准

- [ ] 新功能已实现
- [ ] 现有功能未被破坏
- [ ] 代码符合命名规范和代码量约束
- [ ] 注释已更新
- [ ] 执行报告已输出
