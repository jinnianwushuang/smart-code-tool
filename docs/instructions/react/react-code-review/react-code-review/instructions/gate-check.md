# 门禁检查 — 前置条件

> 执行任何检查任务前，必须先通过以下检查。

## 1. 配置完整性检查

- [ ] `config.md` 中 `ui_framework` 已填写
- [ ] 如开启 i18n 检查，`i18n_locale_files` 已填写

## 2. 项目环境检查

- [ ] 项目根目录存在 `package.json`
- [ ] 项目根目录存在 `.gitignore`（用于排除规则）
- [ ] 如任务指定了检查目录，该目录存在

## 3. 任务信息检查

- [ ] 任务类型已明确（属于 4 种有效类型之一）
- [ ] 检查范围已明确（指定目录或全项目）

## 4. 依赖检查

- [ ] 如执行 ESLint 审计，检查项目中是否存在 ESLint 相关依赖（`eslint`、`eslint-plugin-react`、`eslint-plugin-react-hooks`）

## 检查不通过时

- **停止执行**
- 列出所有不通过的检查项
- 告知使用者需要补充的信息
- 等待使用者回复后再继续
