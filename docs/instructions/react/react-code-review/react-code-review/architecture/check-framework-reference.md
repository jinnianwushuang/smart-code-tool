    ┌──────────────┼──────────────┐
    ▼              ▼              ▼
 ESLint审计    深度审查      i18n专项检查

## 严重级别体系

| 级别 | 含义 | 典型场景 | 处理要求 |
|------|------|----------|----------|
| 🔴 Error | 必须修复 | 内存泄漏、XSS、敏感信息泄露、循环依赖、直接修改 props/state | 立即处理 |
| 🟡 Warning | 建议修复 | 性能隐患、命名不规范、缺少错误处理、Compiler 反模式 | 尽快处理 |
| 🔵 Info | 建议优化 | 代码风格、注释不足、魔法数字 | 酌情处理 |

## 报告文件命名

```
{任务类型}_{检查目标}_{YYYY-MM-DD-HH-mm-ss}.md
```

| 字段 | 取值 |
|------|------|
| 任务类型 | `eslint-audit` / `deep-review` / `full-review` / `i18n-check` |
| 检查目标 | 目录名（如 `user-management`）或 `full-project` |
| 时间戳 | 报告生成时间，`YYYY-MM-DD-HH-mm-ss` 格式 |
