## 使用说明

这些计划书展示了从 0 到 1 构建一套指令集的**思考过程**，包括：

- 如何从模糊需求逐步明确设计决策
- 目录结构的多轮演进与权衡
- 配置项的分类逻辑与优先级
- 文件内容的详细规划
- 执行阶段的拆分策略

在创建新指令集时，可以参照这些计划书的结构和思路，根据自己的架构特点进行调整。
