# 通用步骤 — 各任务复用

> 以下步骤被多个任务指令引用，不可跳过。

## 步骤 A：确定检查范围

```
1. 读取任务命令中的「检查目录」
   → 有值 → 仅检查该目录及其子目录
   → 无值 → 检查整个项目

2. 读取项目根目录的 .gitignore
   → 解析排除规则

3. 读取 config.md 中的 exclude_dirs / exclude_files
   → 合并到排除列表

4. 输出最终检查范围
   → 列出将要扫描的目录和排除规则
```

## 步骤 B：扫描目标文件

```
1. 根据检查范围，收集所有 .vue / .js / .ts 文件
2. 应用排除规则过滤
3. 输出扫描结果：文件数量、文件列表摘要
```

## 步骤 C：逐文件检查

```
1. 按维度逐项检查每个文件
2. 记录发现的问题：
   - 维度名称
   - 文件路径
   - 行号
   - 问题描述
   - 严重级别
3. 按维度分组整理结果
```

## 步骤 D：生成检查报告

```
1. 按 code-standard.md 的格式生成报告
2. 报告文件名：{任务类型}_{检查目标}_{YYYY-MM-DD-HH-mm-ss}.md
3. 保存到 config.md 中指定的 code_review_report_dir
```

## 步骤 E：对比上次报告

```
1. 在报告存放目录中查找相同任务类型 + 相同检查目标的上次报告
2. 如存在：
   → 对比 Error / Warning / Info 数量变化
   → 列出新增问题
   → 列出已解决问题
   → 追加到报告末尾
3. 如不存在：跳过对比
```

## 步骤 F：更新报告总表

```
1. 打开报告存放目录下的 _index.md
2. 如不存在则创建
3. 追加本次检查记录：序号、执行时间、任务类型、检查目标、各级别数量、报告链接
```
