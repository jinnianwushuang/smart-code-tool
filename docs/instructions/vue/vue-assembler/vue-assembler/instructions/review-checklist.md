# 复核自检清单

> AI 完成任何任务后，必须逐项检查以下清单。全部通过后方可结束任务。

## 1. 命名规范

- [ ] 所有新建文件名使用 `kebab-case`
- [ ] 所有变量名使用 `snake_case`
- [ ] 所有函数名使用 `snake_case`，前缀正确
- [ ] 常量使用 `UPPER_SNAKE_CASE`

## 2. 注释

- [ ] 所有注释使用中文（或符合 config.md 配置）
- [ ] 注释比例 ≥ 配置值（默认 10%）
- [ ] 每个导出函数有功能说明注释
- [ ] 复杂逻辑有行内注释

## 3. 代码量

- [ ] 单文件行数 ≤ 配置值（默认 400 行）
- [ ] 单函数行数 ≤ 配置值（默认 50 行）

## 4. 架构合规性

- [ ] 模块职责单一
- [ ] payload 传递正确，无遗漏
- [ ] 无循环依赖
- [ ] 无绕过装配器的手动导入
- [ ] 新模块在 import.meta.glob 扫描范围内

## 5. 状态管理

- [ ] 单例/多例状态使用正确
- [ ] 计算属性无循环依赖
- [ ] init_singleton 正确实现（单例模板）

## 6. 副作用

- [ ] 所有副作用通过 cleanup_effect_* 注册
- [ ] 清理函数返回数组
- [ ] 无框架外手动创建的监听器

## 7. CSS

- [ ] 优先使用框架组件和全局 CSS 变量
- [ ] 无不通用的自定义 CSS
- [ ] 使用的 CSS 变量在 config.md 清单中

## 8. 组件

- [ ] 使用 `<script setup>` 组合式 API
- [ ] 组件对接文档已声明
- [ ] 组件保持单一职责

## 9. 任务完成度

- [ ] 所有需求点已实现
- [ ] 无遗漏的功能项
- [ ] 执行报告已输出
