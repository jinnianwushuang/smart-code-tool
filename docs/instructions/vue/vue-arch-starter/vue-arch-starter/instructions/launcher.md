# 启动器

> AI 助手在接到与代码模板相关的任务时，按本文件定义的流程执行。

## 任务类型识别

根据用户输入中的关键词识别任务类型：

| 任务类型 | 触发关键词 | 说明 |
|----------|-----------|------|
| 新项目集成 | 集成、搭建、初始化、新项目、开始使用 | 引导开发者在新项目中搭建架构骨架 |
| 定制修改 | 定制、修改、替换、换框架、加模块 | 基于已有模板进行定制开发 |

## 标准执行流程

### Step 1：加载上下文

按以下顺序读取文件，建立完整上下文：

1. `config.md` → 确认项目配置（必填项是否完成）
2. `glossary.md` → 理解术语
3. `code-template/dependencies.md` → 了解依赖要求
4. `code-template/vite.config.template.js` → 了解环境配置

### Step 2：门禁检查

执行 `gate-check.md` 定义的前置条件检查。

### Step 3：执行任务

根据识别的任务类型，加载对应的任务指令文件：

- **新项目集成** → 执行 `task-integration.md`
- **定制修改** → 执行 `task-customization.md`

### Step 4：复核

执行完成后，按 `review-checklist.md` 进行自检。

## 存疑即问

- 配置信息不完整时，**必须**先询问用户，禁止猜测
- 不确定的依赖版本或路径，**必须**先确认
- 用户的定制需求超出模板范围时，**必须**说明影响并确认

## 安全熔断

遇到以下情况时，立即停止执行并向用户反馈：

- 缺少必填配置项且无法继续
- 用户的定制需求可能导致架构破坏
- 遇到无法解决的技术问题
