# 复核自检清单

> 任务执行完成后，逐项检查以下清单。

## 集成任务检查

### 配置

- [ ] `config.md` 所有必填项已完成
- [ ] `ui_framework` 选择明确

### 依赖

- [ ] 所有必需依赖已安装
- [ ] 版本与 `dependencies.md` 推荐一致

### 代码

- [ ] `code-template/` 内容已复制到 `src/`
- [ ] 目录结构正确（standardization/ common/ composable/ css/）
- [ ] 无 `.DS_Store` 或其他无关文件

### 路径

- [ ] `vite.config.js` 中 `src/` 别名已配置
- [ ] 所有 import 使用 `src/` 别名，无绝对路径
- [ ] `composable/index.js` 导出路径正确

### 验证

- [ ] 开发服务器可正常启动
- [ ] 验证页面无控制台报错
- [ ] 装配器正常工作（状态机、生命周期、事件通道）

## 定制任务检查

### UI 框架替换

- [ ] CSS 变量文件已替换
- [ ] 所有 Vue 模板中的框架组件标签已替换
- [ ] JS 中的框架 API 调用已替换
- [ ] Vite 插件配置已更新
- [ ] 无框架混用（不能同时存在 Quasar 和 Element Plus 的标签）

### 模块扩展

- [ ] 新模块文件放在正确的目录下
- [ ] 文件名符合约定（`___` 结尾的文件不参与聚合）
- [ ] 模块能被 `import.meta.glob` 扫描到

### 通用

- [ ] 编译无报错
- [ ] 建议用户手动启动项目验证
