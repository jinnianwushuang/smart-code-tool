# 指令集

## 什么是指令集

指令集是一套**面向 AI 助手**的结构化指令文件。将指令集拷贝到目标项目中，修改配置后，AI 助手即可按照指令快速完成符合特定架构规范的开发任务。

核心理念：**复制 → 改配置 → 傻瓜式快速使用**。

## 目录隔离规则

```
docs/instructions/<框架分类>/<指令集名称>/
```

- 第一级：框架分类（vue / react / code-review 等）
- 第二级：指令集名称（vue-assembler / react-assembler 等）
- 用户拷贝的是**最内层指令集目录**的全部内容

## 指令集内部结构

每个指令集目录内部分为两个区域：

| 区域             | 受众      | 说明                                                    |
| ---------------- | --------- | ------------------------------------------------------- |
| `docs/`          | 人类      | 设计架构文档、配置指南、执行流程说明（VitePress 渲染）  |
| `<指令集名称>/`  | AI        | AI 指令文件、配置模板、架构参照（拷贝走的部分）         |
| `code-template/` | 开发者    | 核心代码模板（仅代码模板类指令集，如 vue-arch-starter） |
| `VERSION.md`     | 人类 + AI | 版本号与变更记录                                        |

## 如何使用

1. 将目标指令集目录（如 `vue-assembler/`）整个拷贝到你的项目中
2. 按照 `docs/config-guide.md` 配置指南修改 `config.md`
3. 在 AI 助手中加载 `entry/context-entry.md` 作为入口
4. 按照指令格式提交任务，AI 即可按架构规范执行
