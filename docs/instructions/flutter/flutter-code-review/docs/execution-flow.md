# 执行流程

> AI 助手接收检查任务后的完整执行流程图。

## 总览

```
用户提交检查任务
     │
     ▼
┌──────────────────┐
│ 步骤 1：读取上下文 │
│  config.md        │
│  glossary.md      │
│  check-rules/     │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐     不通过
│ 步骤 2：门禁检查  │ ──────→ 停止，告知缺失项
└────────┬─────────┘
         │ 通过
         ▼
┌──────────────────┐     信息不足
│ 步骤 3：信息完整性│ ──────→ 暂停，向用户提问
└────────┬─────────┘
         │ 充分
         ▼
┌──────────────────┐
│ 步骤 4：识别任务  │
│ 类型             │
│  → analyze-audit │
│  → deep-review   │
│  → full-review   │
│  → i18n-check    │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ 步骤 5：确定范围  │
│  指定目录/全项目  │
│  .gitignore 排除  │
│  exclude 追加排除 │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐     遇到卡点
│ 步骤 6：执行检查  │ ──────→ 安全熔断
│  逐维度扫描       │
└────────┬─────────┘
         │ 完成
         ▼
┌──────────────────┐
│ 步骤 7：生成报告  │
│  带时间戳命名     │
│  对比上次报告     │
│  更新总表         │
└────────┬─────────┘
         │
         ▼
    输出检查报告
```

## 任务提交格式

```
任务类型：<Dart 静态分析审计 | 深度代码审查 | 完整检查 | 国际化专项检查>
检查目录：<目录路径>              ← 可选，不填则全项目
报告地址：<报告输出路径 | 默认>   ← 可选
附加信息：<其他补充>
```
