# 配置指南

> config.md 各配置项详细说明。

## 配置项详解

### 1.1 技术栈配置

| 配置项             | 必填 | 说明                                                          |
| ------------------ | ---- | ------------------------------------------------------------- |
| `state_management` | ✅   | 状态管理方案（getx / riverpod / bloc / provider / 其他）      |
| `use_getx`         | -    | 是否启用 GetX 专项检查（默认 true，随 state_management 推断） |
| `use_material_3`   | -    | 是否启用 Material 3（默认 true）                              |

### 1.2 代码规范阈值

| 配置项               | 默认值 | 说明              |
| -------------------- | ------ | ----------------- |
| `max_file_lines`     | 400    | 单文件最大行数    |
| `max_function_lines` | 50     | 单函数体最大行数  |
| `min_comment_ratio`  | 10     | 注释比例下限（%） |

### 1.3 国际化检查

| 配置项               | 默认值 | 说明                                        |
| -------------------- | ------ | ------------------------------------------- |
| `i18n_check_enabled` | false  | 国际化检查开关                              |
| `i18n_locale_files`  | []     | 语种文件路径列表（arb / GetX translations） |

### 1.4 检查报告配置

| 配置项                   | 默认值                   | 说明         |
| ------------------------ | ------------------------ | ------------ |
| `code_review_report_dir` | `./code-review-reports/` | 报告存放目录 |

### 1.5 排除规则

| 配置项          | 默认值 | 说明                                       |
| --------------- | ------ | ------------------------------------------ |
| `exclude_dirs`  | []     | 额外排除的目录（在 .gitignore 基础上追加） |
| `exclude_files` | []     | 额外排除的文件（在 .gitignore 基础上追加） |

> `.gitignore` 中的规则**默认生效**，无需在此重复配置。生成文件（`*.g.dart`、`*.freezed.dart`）建议默认排除。

### 1.6 命名规范

| 配置项             | 默认值     | 说明                          |
| ------------------ | ---------- | ----------------------------- |
| `file_naming`      | snake_case | 文件命名规则（Dart 官方约定） |
| `variable_naming`  | camelCase  | 变量命名规则                  |
| `class_naming`     | PascalCase | 类/Widget 命名规则            |

## 最小化配置

只需填写 1 项即可开始使用：

```yaml
state_management: 'getx'
```
