# 通用 AI 提示词集

框架无关的通用 AI 编程提示词模板。适用于任何技术栈，**复制后替换 `[方括号]` 内容即可使用**。

---

## A1. 组件/模块开发

> 适用：开发任何新组件、模块、功能单元

```text
请使用 [技术栈，如：React/Vue3/Node.js] 和 [样式库/框架] 编写 [组件/模块名]。
功能要求：
1. [功能点1，如：支持受控和非受控模式]
2. [功能点2，如：点击外部自动关闭]
接口定义：包含 TypeScript 类型定义，Props/Params 需包含 [字段列表]。
交互细节：[如：进入/退出动画、错误状态显示]。
代码风格：逻辑与视图分离，复杂逻辑提取为独立函数/Hook/Composable。
```

---

## A2. Bug 调试/逻辑诊断

> 适用：报错、样式失效、逻辑不符预期

```text
我遇到一个 [环境，如：Chrome 120/Node 20/iOS Safari] 下的 Bug。
现象描述：[如：点击按钮后状态没有更新，控制台无报错]。
相关代码：
[粘贴代码段]
我的尝试：已试过 [方法]，但没有效果。
请帮我：
1. 诊断可能的原因
2. 给出修复后的代码
3. 解释为什么会发生这种情况
```

---

## A3. 代码重构/优化

> 适用：提高可维护性、解决性能隐患

```text
这段代码目前运行正常，但我认为 [痛点，如：逻辑太乱 / 有性能隐患 / 重复代码多]。
代码：
[粘贴代码]
目标：
1. 按 [原则，如：SOLID / 单一职责 / DRY] 进行重构
2. 优化 [具体点，如：减少不必要的重新渲染 / 降低时间复杂度]
3. 保持功能不变，提供核心变更说明
```

---

## A4. 复杂数据处理

> 适用：JSON 转换、树结构、日期计算、统计聚合

```text
我有以下原始数据：
[粘贴数据或描述结构]
需要转换成以下格式供 [使用场景，如：图表渲染/树组件] 使用：
[期望的数据结构示例]
要求：
1. 使用 [原生 JS / Lodash / 指定库] 实现
2. 考虑边界情况（数据为空、字段缺失、类型异常）
3. 封装为纯函数，无副作用
```

---

## 提问技巧

1. **赋予角色**：开头加「你是一名资深前端工程师，精通 [技术栈]」
2. **给例子（Few-Shot）**：贴上你偏好的代码风格片段，告诉 AI「按这个风格输出」
3. **分步思考**：复杂逻辑前加「请先分析实现思路，再生成代码」，降低逻辑错误率
4. **版本强制**：声明具体版本（如「基于 Vue 3.4+」），避免 AI 输出过时语法
