# Vue 提示词集

面向 Vue 3 开发场景的 AI 提示词集合。每个 Prompt 用代码块包裹，**复制后替换 `[方括号]` 内容即可直接使用**。

## B. Vue 组件开发（日常高频）

## VB1. 新建基础组件

> 适用：创建一个标准 Vue 3 组件，含完整 TS 类型定义

```text
请使用 Vue 3 (<script setup>) + TypeScript 编写 [组件名] 组件。
技术栈：[组件库，如 Ant Design Vue / Element Plus / 无] + [样式方案，如 Scoped SCSS / Tailwind]
功能：
1. [功能点1，如：通过 v-model 绑定输入值]
2. [功能点2，如：点击外部自动关闭]
要求：
- Props 使用 defineProps<T> 泛型定义，包含默认值
- Emits 使用 defineEmits 并声明类型
- 暴露方法使用 defineExpose
- 复杂逻辑提取为 composable
```

## VB2. 新建表单组件

> 适用：带校验、联动、错误提示的表单组件

```text
请使用 Vue 3 + [组件库] 编写 [表单名，如：用户注册] 表单组件。
字段：
1. [字段1，如：用户名] - [校验规则，如：必填 + 最少3字符]
2. [字段2，如：手机号] - [校验规则，如：正则校验]
3. [字段3，如：邮箱] - [校验规则，如：异步校验是否已注册]
联动逻辑：当 [条件字段] 值为 [某值] 时，显示/隐藏 [目标字段]
要求：
- 使用 defineModel 双向绑定表单数据
- 校验规则使用 [组件库] 的 rules 配置
- 提交时触发 @submit 事件，传递校验通过的数据
- 支持 reset 方法清空表单和校验状态
```

## VB3. 新建列表/表格组件

> 适用：带分页、搜索、排序的数据列表

```text
请使用 Vue 3 + [组件库] 封装 [业务名，如：订单管理] 高级搜索列表组件。
搜索栏：[输入框、下拉选择、日期范围] 等 [N] 个筛选条件，支持展开/收起
表格列：序号、[字段1]、[字段2]、状态标签（不同状态不同颜色）、操作列（编辑/删除）
要求：
- 使用 composable (useTable) 封装分页、请求、搜索重置逻辑
- 接口调用使用 const res = await [apiMethod](params) 形式
- 支持行选择、列排序
- 响应式适配：表格高度自适应，支持内部滚动
- 空状态和 Loading 状态处理
```
