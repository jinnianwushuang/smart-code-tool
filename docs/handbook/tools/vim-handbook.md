Vim（Vi Improved）是一款功能强大的模式化文本编辑器，被誉为"编辑器之神"。它完全基于键盘操作，无需鼠标，熟练后编辑效率极高。以下是Vim的完整使用指南，涵盖从入门到进阶的核心内容。

## 一、Vim的核心概念：模式化编辑

Vim与传统编辑器的最大区别在于其**模式化编辑**理念。Vim拥有多种操作模式，其中最重要的是以下三种：

| **模式**                         | **功能描述**                                                 |
| -------------------------------- | ------------------------------------------------------------ |
| **普通模式（Normal mode）**      | 控制光标移动、删除字符/行、复制粘贴、进入其他模式。刚打开Vim时默认在此模式。 |
| **插入模式（Insert mode）**      | 可以输入文字，像普通编辑器一样。按 i、a、o 等从命令模式进入，按 ESC 返回命令模式。 |
| **命令行模式（Last line mode）** | 用于保存文件、退出Vim、查找替换、设置行号等。在命令模式下按 : 进入。 |

此外，还有可视模式（Visual mode）、选择模式、Ex模式等，总计12种模式，但初级阶段掌握上述三种足够。

## 二、基本操作流程

### 启动与退出Vim

```bash
# 打开文件
vim filename

# 退出命令（在命令行模式下）
:q                  # 退出（文件未修改时）
:q!                 # 强制退出不保存
:wq 或 :x 或 ZZ     # 保存并退出
:w                  # 仅保存文件
```

### 编辑流程

```
打开文件 → 按 i 进入插入模式 → 输入文字 → 按 ESC 返回普通模式 → 输入 :wq 保存退出
```

## 三、普通模式常用命令

### 3.1 光标移动

#### 基本移动
- `h` / `j` / `k` / `l`：左/下/上/右移动

#### 单词移动
- `w`：跳到下一个单词开头
- `b`：跳到上一个单词开头
- `e`：跳到单词末尾

#### 行内移动
- `0` 或 `^`：跳到行首（`^`跳到第一个非空字符）
- `$`：跳到行尾

#### 文件级移动
- `gg`：跳到文件首行
- `G`：跳到文件末行
- `nG` 或 `:n`：跳到第n行

#### 翻页操作
- `Ctrl+f` / `Ctrl+b`：向前/向后翻一页
- `Ctrl+d` / `Ctrl+u`：向前/向后翻半页

### 3.2 删除操作

| **命令** | **作用**              |
| -------- | --------------------- |
| x        | 删除光标所在字符      |
| nx       | 删除光标后n个字符     |
| X        | 删除光标前一个字符    |
| dd       | 删除整行              |
| ndd      | 删除从当前行开始的n行 |
| d$ 或 D  | 删除从光标到行尾      |
| d0       | 删除从行首到光标      |
| dw       | 删除到下一个单词开头  |

### 3.3 复制与粘贴

| **命令** | **作用**           |
| -------- | ------------------ |
| yy       | 复制当前行         |
| nyy      | 复制n行            |
| yw       | 复制光标到单词末尾 |
| p        | 粘贴到光标后       |
| P        | 粘贴到光标前       |

### 3.4 撤销与重做

- `u`：撤销上一次操作
- `Ctrl+r`：恢复撤销的操作
- `.`：重复上一个操作

### 3.5 替换操作

- `r`：替换光标处的一个字符
- `R`：连续替换多个字符（覆盖模式）

## 四、命令行模式常用命令

### 4.1 文件操作

| **命令**    | **作用**                 |
| ----------- | ------------------------ |
| :w          | 保存文件                 |
| :q          | 退出（未保存会提示）     |
| :q!         | 强制退出不保存           |
| :wq 或 :x   | 保存并退出               |
| :w newfile  | 另存为新文件             |
| :e filename | 打开指定文件             |
| :e!         | 重新加载文件（放弃修改） |
| :r filename | 读取文件内容到光标位置   |

### 4.2 显示设置

```vim
:set nu           " 显示行号
:set nonu         " 取消行号
:set hlsearch     " 高亮查找结果
:set nohlsearch   " 取消查找高亮
:syntax on        " 启用语法高亮
```

### 4.3 搜索与替换

#### 搜索操作

- `/关键字`：向下搜索关键字，按 `n` 继续下一个
- `?关键字`：向上搜索关键字，按 `N` 继续上一个
- `*`：向下搜索光标所在单词
- `#`：向上搜索光标所在单词

#### 替换操作

```vim
:s/old/new/           " 替换当前行第一个old为new
:s/old/new/g          " 替换当前行所有old为new
:%s/old/new/g         " 全局替换所有old为new
:%s/old/new/gc        " 全局替换（逐个确认）
:n,ms/old/new/g       " 替换n到m行所有old为new
```

### 4.4 多窗口与多文件操作

#### 窗口分割

- `:split` 或 `:sp`：水平分割窗口
- `:vsplit` 或 `:vs`：垂直分割窗口
- `Ctrl+w, w`：在窗口间切换
- `Ctrl+w, h/j/k/l`：分别向左/下/上/右切换窗口
- `:q`：关闭当前窗口

#### 多文件操作

- `:e filename`：打开指定文件
- `:bn`：切换到下一个缓冲区
- `:bp`：切换到上一个缓冲区
- `:ls`：列出所有缓冲区

## 五、可视化模式

可视化模式用于选中文本块进行批量操作：

| **快捷键** | **模式**               |
| ---------- | ---------------------- |
| v          | 字符选择模式           |
| V          | 行选择模式             |
| Ctrl+v     | 块选择模式（矩形区域） |

选中文本后，可以执行以下操作：
- `d`：删除
- `y`：复制
- `c`：修改
- `>`：向右缩进
- `<`：向左缩进

## 六、进阶操作

### 6.1 寄存器系统

Vim使用寄存器存储复制的文本：

- `""`：默认寄存器
- `"0-"9`：数字寄存器（自动存储删除和复制内容）
- `"a-"z`：命名寄存器（用户自定义）
- `"+`：系统剪贴板寄存器

#### 使用示例

```vim
"ayy        " 复制当前行到寄存器a
"ap         " 粘贴寄存器a的内容
"+y         " 复制到系统剪贴板
"+p         " 从系统剪贴板粘贴
```

### 6.2 宏录制与执行

宏是自动化重复操作的强大工具：

```vim
qa          " 开始录制宏到寄存器a
q           " 停止录制
@a          " 执行宏a
@@          " 重复执行上一个宏
10@a        " 执行宏a十次
```

### 6.3 文本对象

文本对象用于精确操作特定文本结构：

| **对象** | **含义**                  |
| -------- | ------------------------- |
| iw       | 单词内部                  |
| aw       | 整个单词（含空格）        |
| i", a"   | 引号内部/整个引号区域     |
| i(, a(   | 括号内部/整个括号区域     |
| i{, a{   | 花括号内部/整个花括号区域 |
| ip, ap   | 段落内部/整个段落         |

#### 使用示例
- `ciw`：改变单词内容
- `di(`：删除括号内内容
- `yap`：复制整个段落

### 6.4 书签（Marks）

书签用于快速跳转到标记位置：

```vim
ma          " 设置书签a（局部）
mA          " 设置书签A（全局）
'a          " 跳转到书签a的行首
`a          " 跳转到书签a的精确位置
:marks      " 查看所有书签
:delmarks a " 删除书签a
```

## 七、Vim配置（~/.vimrc）

Vim的个性化配置通过主目录下的 `.vimrc` 文件实现。以下是一个基础配置示例：

```vim
" 基本设置
syntax on                    " 语法高亮
set nu                       " 显示行号
set cursorline               " 高亮当前行
set laststatus=2             " 显示状态栏

" 缩进设置
set tabstop=4                " Tab键宽度为4空格
set shiftwidth=4             " 自动缩进宽度
set expandtab                " 将Tab转换为空格
set autoindent               " 自动缩进
set smartindent              " 智能缩进

" 搜索设置
set hlsearch                 " 搜索高亮
set incsearch                " 增量搜索
set ignorecase               " 搜索忽略大小写
set smartcase                " 智能大小写匹配

" 其他设置
set wildmenu                 " 命令行补全
```

### 配置生效

修改 `.vimrc` 后，在Vim中执行以下命令重新加载配置：

```vim
:source ~/.vimrc
```

## 八、学习建议

1. **从基础开始**：先用Vim新建一个文本文件，练习光标移动、删除、复制、粘贴等基本操作
2. **记住三个核心**：
   - `i`：进入插入模式
   - `ESC`：返回普通模式
   - `:wq`：保存退出
3. **循序渐进**：先掌握常用命令，再逐步学习高级功能
4. **内置教程**：在终端输入 `vimtutor` 可启动Vim自带的交互式教程
5. **坚持使用**：Vim的学习曲线较陡，但只要坚持使用一周，你就能体会到手不离键盘的编辑方式
