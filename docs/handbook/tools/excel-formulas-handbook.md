## 1. 基础函数

### 1.1 SUM - 求和

```plaintext
' 基本用法
=SUM(A1:A10)                    ' 对 A1 到 A10 求和
=SUM(A1, B1, C1)                ' 对多个单元格求和
=SUM(A1:A10, C1:C10)            ' 对多个区域求和

' 条件求和（配合其他函数）
=SUMIF(A1:A10, ">100")          ' 对大于 100 的值求和
=SUMIFS(C1:C10, A1:A10, ">100", B1:B10, "北京")  ' 多条件求和
```

**示例**：
| | A | B | C |
|---|---|---|---|
| 1 | 产品 | 城市 | 销售额 |
| 2 | 苹果 | 北京 | 100 |
| 3 | 香蕉 | 上海 | 200 |
| 4 | 苹果 | 北京 | 150 |
| 5 | =SUM(C2:C4) | → 450 | |
| 6 | =SUMIFS(C2:C4, A2:A4, "苹果", B2:B4, "北京") | → 250 | |

### 1.2 AVERAGE - 平均值

```plaintext
=AVERAGE(A1:A10)                  ' 计算平均值
=AVERAGEIF(A1:A10, ">0")          ' 条件平均值
=AVERAGEIFS(C1:C10, A1:A10, "苹果")  ' 多条件平均值
```

### 1.3 COUNT 系列 - 计数

```plaintext
=COUNT(A1:A10)                    ' 计数数字单元格
=COUNTA(A1:A10)                   ' 计数非空单元格
=COUNTBLANK(A1:A10)               ' 计数空白单元格
=COUNTIF(A1:A10, ">100")          ' 条件计数
=COUNTIFS(A1:A10, ">100", B1:B10, "北京")  ' 多条件计数
```

**示例**：
| | A | B |
|---|---|---|
| 1 | 姓名 | 成绩 |
| 2 | 张三 | 85 |
| 3 | 李四 | 92 |
| 4 | 王五 | |
| 5 | =COUNTA(A2:A4) | → 3 |
| 6 | =COUNT(B2:B4) | → 2 |
| 7 | =COUNTBLANK(B2:B4) | → 1 |
| 8 | =COUNTIF(B2:B4, ">=90") | → 1 |

### 1.4 MAX/MIN - 最大最小值

```plaintext
=MAX(A1:A10)                      ' 最大值
=MIN(A1:A10)                      ' 最小值
=MAXIFS(C1:C10, A1:A10, "苹果")   ' 条件最大值
=MINIFS(C1:C10, A1:A10, "苹果")   ' 条件最小值
```

## 2. 逻辑函数

### 2.1 IF - 条件判断

```plaintext
' 基本语法
=IF(条件, 真值, 假值)

' 单层判断
=IF(A1>60, "及格", "不及格")

' 多层嵌套
=IF(A1>=90, "优秀", IF(A1>=80, "良好", IF(A1>=60, "及格", "不及格")))

' 结合 AND/OR
=IF(AND(A1>60, B1>60), "双科及格", "有不及格")
=IF(OR(A1>90, B1>90), "至少一科优秀", "无优秀")
```

**示例**：成绩评级
| | A | B |
|---|---|---|
| 1 | 分数 | 等级 |
| 2 | 95 | =IF(A2>=90,"优秀",IF(A2>=80,"良好",IF(A2>=60,"及格","不及格"))) → 优秀 |
| 3 | 75 | → 及格 |
| 4 | 85 | → 良好 |

### 2.2 IFS - 多条件判断（Excel 2019+）

```plaintext
' 简化多层 IF
=IFS(A1>=90, "优秀", A1>=80, "良好", A1>=60, "及格", TRUE, "不及格")
```

### 2.3 SWITCH - 精确匹配（Excel 2019+）

```plaintext
=SWITCH(A1, 1, "一月", 2, "二月", 3, "三月", "其他")
```

### 2.4 AND/OR/NOT - 逻辑运算

```plaintext
=AND(A1>0, A1<100)                ' 所有条件为真则返回 TRUE
=OR(A1>90, B1>90)                 ' 任一条件为真则返回 TRUE
=NOT(A1=0)                        ' 取反
```

**实际应用**：

```plaintext
' 判断是否在范围内
=IF(AND(A1>=60, A1<=100), "有效", "无效")

' 判断是否满足任一条件
=IF(OR(B1="北京", B1="上海", B1="广州"), "一线城市", "其他")
```

### 2.5 IFERROR - 错误处理

```plaintext
=IFERROR(A1/B1, "除数不能为零")
=IFERROR(VLOOKUP(A1, D:E, 2, FALSE), "未找到")
=IFNA(VLOOKUP(A1, D:E, 2, FALSE), "不存在")  ' 仅处理 #N/A 错误
```

## 3. 查找与引用

### 3.1 VLOOKUP - 垂直查找

```plaintext
' 基本语法
=VLOOKUP(查找值, 查找范围, 返回列号, [精确匹配])

' 精确匹配
=VLOOKUP(A2, D:F, 3, FALSE)       ' 在 D 列查找 A2，返回 F 列对应值

' 近似匹配（需排序）
=VLOOKUP(A2, D:F, 3, TRUE)
```

**示例**：
| | A | B | | D | E | F |
|---|---|---|---|---|---|---|
| 1 | 学号 | 姓名 | | 学号 | 姓名 | 成绩 |
| 2 | 1001 | =VLOOKUP(A2,D2:F4,2,FALSE) → 张三 | | 1001 | 张三 | 85 |
| 3 | 1002 | → 李四 | | 1002 | 李四 | 92 |
| 4 | 1003 | → 王五 | | 1003 | 王五 | 78 |

**注意事项**：

- 查找值必须在查找范围的第一列
- 返回列号从 1 开始计数
- FALSE 表示精确匹配，TRUE 表示近似匹配

### 3.2 HLOOKUP - 水平查找

```plaintext
=HLOOKUP(A1, B1:D5, 3, FALSE)     ' 在第一行查找，返回第 3 行
```

### 3.3 INDEX + MATCH - 灵活查找（推荐）

```plaintext
' 基本语法
=INDEX(返回范围, MATCH(查找值, 查找范围, 0))

' 双向查找
=INDEX(C2:C10, MATCH(A2, B2:B10, 0))

' 行列双向定位
=INDEX(B2:D10, MATCH("李四", A2:A10, 0), MATCH("数学", B1:D1, 0))
```

**示例**：
| | A | B | C | D |
|---|---|---|---|---|
| 1 | 姓名 | 语文 | 数学 | 英语 |
| 2 | 张三 | 85 | 90 | 88 |
| 3 | 李四 | 92 | 95 | 91 |
| 4 | =INDEX(B2:D4, MATCH("李四",A2:A4,0), MATCH("数学",B1:D1,0)) → 95 | | | |

**优势**：

- 可以从任意列返回结果
- 不受列位置限制
- 性能优于 VLOOKUP

### 3.4 XLOOKUP - 新一代查找（Excel 365/2021+）

```plaintext
' 基本语法
=XLOOKUP(查找值, 查找范围, 返回范围, [未找到提示], [匹配模式], [搜索模式])

' 精确匹配
=XLOOKUP(A2, D:D, F:F, "未找到")

' 反向查找
=XLOOKUP(A2, D:D, F:F, "未找到", 0, -1)  ' 从后往前找

' 模糊匹配
=XLOOKUP(A2, D:D, F:F, "未找到", 2)      ' 小于等于的最大值
```

**示例**：

```plaintext
' 替代 VLOOKUP
=XLOOKUP(A2, D2:D100, F2:F100, "未找到")

' 多列返回（动态数组）
=XLOOKUP(A2, D2:D100, F2:H100, "未找到")  ' 返回 3 列
```

### 3.5 INDIRECT - 间接引用

```plaintext
' 引用其他工作表
=INDIRECT("'" & A1 & "'!B2")      ' A1 中存储工作表名称

' 动态范围
=SUM(INDIRECT("A1:A" & B1))       ' B1 中存储行数

' R1C1 样式
=INDIRECT("R5C3", FALSE)          ' 引用第 5 行第 3 列（C5）
```

### 3.6 OFFSET - 偏移引用

```plaintext
' 基本语法
=OFFSET(起点, 行偏移, 列偏移, [高度], [宽度])

' 简单偏移
=OFFSET(A1, 2, 3)                 ' 从 A1 向下 2 行，向右 3 列（D3）

' 动态范围
=SUM(OFFSET(A1, 0, 0, B1, 1))     ' 从 A1 开始，高度为 B1 的区域求和
```

## 4. 文本函数

### 4.1 LEFT/RIGHT/MID - 提取文本

```plaintext
=LEFT(A1, 3)                      ' 从左侧提取 3 个字符
=RIGHT(A1, 2)                     ' 从右侧提取 2 个字符
=MID(A1, 2, 5)                    ' 从第 2 位开始提取 5 个字符
```

**示例**：
| | A | B | C | D |
|---|---|---|---|---|
| 1 | 身份证号 | 年份 | 地区码 | 性别 |
| 2 | 110101199001011234 | =MID(A2,7,4) → 1990 | =LEFT(A2,6) → 110101 | =MOD(MID(A2,17,1),2) → 男 |

### 4.2 LEN - 文本长度

```plaintext
=LEN(A1)                          ' 字符数
=LENB(A1)                         ' 字节数（中文占 2 字节）
```

### 4.3 FIND/SEARCH - 查找位置

```plaintext
=FIND("@", A1)                    ' 查找 @ 的位置（区分大小写）
=SEARCH("@", A1)                  ' 查找 @ 的位置（不区分大小写）

' 提取邮箱用户名
=LEFT(A1, FIND("@", A1) - 1)
```

### 4.4 SUBSTITUTE/REPLACE - 替换文本

```plaintext
=SUBSTITUTE(A1, "旧文本", "新文本")           ' 替换所有匹配
=SUBSTITUTE(A1, "旧文本", "新文本", 1)        ' 替换第 1 个匹配

=REPLACE(A1, 起始位置, 字符数, "新文本")      ' 按位置替换
```

**示例**：

```plaintext
' 去除空格
=SUBSTITUTE(A1, " ", "")

' 替换分隔符
=SUBSTITUTE(A1, ",", "-")

' 隐藏手机号中间四位
=REPLACE(A1, 4, 4, "****")
```

### 4.5 CONCAT/TEXTJOIN - 文本连接

```plaintext
' 旧版
=A1 & " " & B1                    ' 连接文本
=CONCATENATE(A1, " ", B1)

' 新版（Excel 2019+）
=CONCAT(A1, " ", B1)              ' 连接多个文本
=TEXTJOIN(" ", TRUE, A1, B1, C1)  ' 用分隔符连接，忽略空值
```

**示例**：
| | A | B | C | D |
|---|---|---|---|---|
| 1 | 姓 | 名 | | 全名 |
| 2 | 张 | 三 | | =TEXTJOIN("", TRUE, A2, B2) → 张三 |
| 3 | 李 | | | =TEXTJOIN("", TRUE, A3, B3) → 李 |

### 4.6 TRIM/CLEAN - 清理文本

```plaintext
=TRIM(A1)                         ' 去除首尾空格，中间多余空格
=CLEAN(A1)                        ' 去除不可打印字符
```

### 4.7 UPPER/LOWER/PROPER - 大小写转换

```plaintext
=UPPER(A1)                        ' 转大写
=LOWER(A1)                        ' 转小写
=PROPER(A1)                       ' 首字母大写
```

### 4.8 TEXT - 格式化文本

```plaintext
=TEXT(A1, "yyyy-mm-dd")           ' 日期格式化
=TEXT(A1, "#,##0.00")             ' 数字格式化
=TEXT(A1, "0%")                   ' 百分比格式化
```

**常用格式代码**：

```
yyyy-mm-dd    2024-01-15
mm/dd/yyyy    01/15/2024
#,##0.00      1,234.56
0%            85%
$#,##0.00     $1,234.56
```

## 5. 日期与时间

### 5.1 TODAY/NOW - 当前日期时间

```plaintext
=TODAY()                          ' 当前日期（动态更新）
=NOW()                            ' 当前日期和时间（动态更新）
```

### 5.2 YEAR/MONTH/DAY - 提取日期部分

```plaintext
=YEAR(A1)                         ' 提取年份
=MONTH(A1)                        ' 提取月份
=DAY(A1)                          ' 提取日
=WEEKDAY(A1, 2)                   ' 星期几（1=周一，7=周日）
```

**示例**：
| | A | B | C | D |
|---|---|---|---|---|
| 1 | 日期 | 年 | 月 | 星期 |
| 2 | 2024-01-15 | =YEAR(A2) → 2024 | =MONTH(A2) → 1 | =TEXT(A2,"aaaa") → 星期一 |

### 5.3 DATE - 构建日期

```plaintext
=DATE(2024, 1, 15)                ' 构建日期：2024-01-15
=DATE(YEAR(A1), MONTH(A1)+1, 1)   ' 下月第一天
```

### 5.4 DATEDIF - 日期差

```plaintext
' 计算两个日期之间的差异
=DATEDIF(开始日期, 结束日期, "单位")

' 单位参数
"Y"   整年数
"M"   整月数
"D"   天数
"YM"  忽略年和天的月数差
"MD"  忽略年和月的天数差
"YD"  忽略年的天数差
```

**示例**：

```plaintext
' 计算年龄
=DATEDIF(A1, TODAY(), "Y")

' 计算工龄
=DATEDIF(入职日期, TODAY(), "Y") & "年" & DATEDIF(入职日期, TODAY(), "YM") & "个月"

' 计算项目天数
=DATEDIF(开始日期, 结束日期, "D")
```

### 5.5 EOMONTH - 月末日期

```plaintext
=EOMONTH(A1, 0)                   ' 当月最后一天
=EOMONTH(A1, 1)                   ' 下月最后一天
=EOMONTH(A1, -1)                  ' 上月最后一天
```

### 5.6 WORKDAY/NETWORKDAYS - 工作日计算

```plaintext
=WORKDAY(开始日期, 天数, [节假日])           ' 工作日后的日期
=NETWORKDAYS(开始日期, 结束日期, [节假日])   ' 工作日天数
```

**示例**：

```plaintext
' 10 个工作日后的日期
=WORKDAY(TODAY(), 10)

' 本月工作日天数
=NETWORKDAYS(DATE(YEAR(TODAY()),MONTH(TODAY()),1), EOMONTH(TODAY(),0))
```

### 5.7 EDATE - 月份加减

```plaintext
=EDATE(A1, 3)                     ' 3 个月后的日期
=EDATE(A1, -6)                    ' 6 个月前的日期
```

## 6. 数学与统计

### 6.1 ROUND 系列 - 舍入

```plaintext
=ROUND(A1, 2)                     ' 四舍五入到 2 位小数
=ROUNDUP(A1, 0)                   ' 向上舍入到整数
=ROUNDDOWN(A1, 0)                 ' 向下舍入到整数
=INT(A1)                          ' 取整（向零方向）
=TRUNC(A1)                        ' 截断小数
```

### 6.2 MOD - 取余

```plaintext
=MOD(A1, 2)                       ' 除以 2 的余数（判断奇偶）
=MOD(A1, 7)                       ' 除以 7 的余数
```

**应用**：

```plaintext
' 判断奇偶
=IF(MOD(A1,2)=0, "偶数", "奇数")

' 隔行着色
=MOD(ROW(),2)=0                   ' 偶数行
```

### 6.3 POWER/SQRT - 幂运算

```plaintext
=POWER(A1, 2)                     ' A1 的平方
=A1^2                             ' 同上
=SQRT(A1)                         ' 平方根
```

### 6.4 ABS - 绝对值

```plaintext
=ABS(A1)                          ' 绝对值
```

### 6.5 RANK - 排名

```plaintext
=RANK.EQ(A1, $A$1:$A$10, 0)       ' 降序排名（默认）
=RANK.EQ(A1, $A$1:$A$10, 1)       ' 升序排名
```

**示例**：
| | A | B |
|---|---|---|
| 1 | 成绩 | 排名 |
| 2 | 95 | =RANK.EQ(A2,$A$2:$A$11,0) → 1 |
| 3 | 88 | → 3 |
| 4 | 92 | → 2 |

### 6.6 LARGE/SMALL - 第 N 大/小值

```plaintext
=LARGE(A1:A10, 1)                 ' 最大值
=LARGE(A1:A10, 2)                 ' 第二大值
=SMALL(A1:A10, 1)                 ' 最小值
=SMALL(A1:A10, 3)                 ' 第三小值
```

### 6.7 MEDIAN - 中位数

```plaintext
=MEDIAN(A1:A10)                   ' 中位数
```

### 6.8 MODE - 众数

```plaintext
=MODE.SNGL(A1:A10)                ' 单个众数
=MODE.MULT(A1:A10)                ' 多个众数（数组公式）
```

## 7. 财务函数

### 7.1 PMT - 等额本息还款

```plaintext
=PMT(利率/12, 期数, 贷款金额)

' 示例：贷款 100 万，年利率 4.9%，20 年
=PMT(4.9%/12, 20*12, 1000000)     → -6,544.44
```

### 7.2 FV - 未来值

```plaintext
=FV(利率, 期数, 每期支付, [现值], [类型])

' 示例：每月存 1000，年利率 3%，10 年后
=FV(3%/12, 10*12, -1000)          → 139,741.57
```

### 7.3 PV - 现值

```plaintext
=PV(利率, 期数, 每期支付, [未来值], [类型])

' 示例：10 年后需要 20 万，年利率 3%，现在需存多少
=PV(3%, 10, 0, -200000)           → 148,818.88
```

### 7.4 RATE - 利率

```plaintext
=RATE(期数, 每期支付, 现值, [未来值])

' 示例：贷款 100 万，每月还 6000，20 年还清，求利率
=RATE(20*12, -6000, 1000000)*12   → 4.27%
```

### 7.5 NPV/IRR - 投资评估

```plaintext
=NPV(折现率, 现金流1, 现金流2, ...)     ' 净现值
=IRR(现金流范围)                         ' 内部收益率
```

**示例**：
| | A | B |
|---|---|---|
| 1 | 年份 | 现金流 |
| 2 | 0 | -100000 |
| 3 | 1 | 30000 |
| 4 | 2 | 35000 |
| 5 | 3 | 40000 |
| 6 | 4 | 45000 |
| 7 | NPV: | =NPV(10%, B3:B6)+B2 → 12,396.69 |
| 8 | IRR: | =IRR(B2:B6) → 17.32% |

## 8. 数组公式

### 8.1 传统数组公式（Ctrl+Shift+Enter）

```plaintext
' 多条件求和
{=SUM((A1:A10="苹果")*(B1:B10="北京")*C1:C10)}

' 多条件计数
{=SUM((A1:A10="苹果")*(B1:B10>100))}

' 查找并返回多个值
{=INDEX(C1:C10, SMALL(IF(A1:A10="苹果", ROW(A1:A10)-ROW(A1)+1), ROW(A1)))}
```

**输入方法**：

1. 输入公式（不含花括号）
2. 按 `Ctrl + Shift + Enter`
3. Excel 自动添加花括号 `{}`

### 8.2 SUMPRODUCT - 数组乘积求和

```plaintext
' 多条件求和（无需数组公式）
=SUMPRODUCT((A1:A10="苹果")*(B1:B10="北京")*C1:C10)

' 加权平均
=SUMPRODUCT(A1:A10, B1:B10) / SUM(B1:B10)

' 多条件计数
=SUMPRODUCT((A1:A10="苹果")*(B1:B10>100)*1)
```

**示例**：
| | A | B | C |
|---|---|---|---|
| 1 | 产品 | 城市 | 销售额 |
| 2 | 苹果 | 北京 | 100 |
| 3 | 香蕉 | 上海 | 200 |
| 4 | 苹果 | 北京 | 150 |
| 5 | =SUMPRODUCT((A2:A4="苹果")*(B2:B4="北京")*C2:C4) → 250 | | |

## 9. 动态数组公式（Excel 365/2021+）

### 9.1 FILTER - 筛选数据

```plaintext
' 基本语法
=FILTER(数据范围, 条件, [未找到提示])

' 单条件筛选
=FILTER(A2:C100, B2:B100="北京")

' 多条件筛选
=FILTER(A2:C100, (B2:B100="北京")*(C2:C100>100))

' 多条件 OR
=FILTER(A2:C100, (B2:B100="北京")+(B2:B100="上海"))
```

**示例**：
| | A | B | C | | E | F | G |
|---|---|---|---|---|---|---|---|
| 1 | 姓名 | 城市 | 销售额 | | 筛选结果 | | |
| 2 | 张三 | 北京 | 100 | | =FILTER(A2:C4, B2:B4="北京") | | |
| 3 | 李四 | 上海 | 200 | | 张三 | 北京 | 100 |
| 4 | 王五 | 北京 | 150 | | 王五 | 北京 | 150 |

### 9.2 SORT - 排序

```plaintext
' 基本语法
=SORT(数据范围, [排序列], [排序方式], [按列排序])

' 单列排序
=SORT(A2:C10, 3, -1)              ' 按第 3 列降序

' 多列排序
=SORT(A2:C10, {2,3}, {1,-1})      ' 先按第 2 列升序，再按第 3 列降序
```

**示例**：

## 10. 实用案例

### 10.1 数据验证与清洗

```plaintext

=UNIQUE(A2:A100)

' 2. 去除空格
=TRIM(A1)

' 3. 统一大小写
=PROPER(A1)

' 4. 提取数字
=TEXTJOIN("", TRUE, IF(ISNUMBER(MID(A1, ROW(INDIRECT("1:"&LEN(A1))), 1)*1), MID(A1, ROW(INDIRECT("1:"&LEN(A1))), 1), ""))

' 5. 验证邮箱格式
=IF(ISNUMBER(FIND("@", A1)), "有效", "无效")

```

### 10.2 财务报表

```plaintext
' 1. 计算毛利率
=(销售收入 - 成本) / 销售收入

' 2. 计算同比增长率
=(本期 - 上期) / 上期

' 3. 计算累计值
=SUM($B$2:B2)                     ' 下拉填充

' 4. 预算 vs 实际差异
=实际值 - 预算值
=IF(实际值 > 预算值, "超支", "节约")

=IF(累计占比 <= 0.8, "A", IF(累计占比 <= 0.95, "B", "C"))
```

### 10.9 组合公式实战

#### 案例 1：提取身份证信息

```plaintext
' 假设 A2 为身份证号：110101199001011234

' 提取出生日期
=DATE(MID(A2,7,4), MID(A2,11,2), MID(A2,13,2))

' 提取性别（奇数男，偶数女）
=IF(MOD(MID(A2,17,1),2)=1, "男", "女")

' 计算年龄
=DATEDIF(DATE(MID(A2,7,4), MID(A2,11,2), MID(A2,13,2)), TODAY(), "Y")

' 提取地区码
=LEFT(A2, 6)
```

#### 案例 2：智能查找

```plaintext
' 多条件查找（INDEX + MATCH 数组公式）
=INDEX(C2:C100, MATCH(1, (A2:A100="苹果")*(B2:B100="北京"), 0))

' 输入后按 Ctrl+Shift+Enter

' 或使用 SUMPRODUCT
=INDEX(C2:C100, SUMPRODUCT((A2:A100="苹果")*(B2:B100="北京")*ROW(A2:A100))-ROW(A2)+1)
```

#### 案例 3：动态汇总

```plaintext
' 按月汇总销售额
=SUMPRODUCT((MONTH(日期范围)=1)*(销售额范围))

' 按季度汇总
=SUMPRODUCT((ROUNDUP(MONTH(日期范围)/3,0)=1)*(销售额范围))

' 按周汇总
=SUMPRODUCT((WEEKNUM(日期范围,2)=1)*(销售额范围))
```

#### 案例 4：数据透视替代

```plaintext
' 部门销售额汇总（动态数组）
=LET(
    depts, UNIQUE(B2:B100),
    totals, MAP(depts, LAMBDA(d, SUMIFS(C2:C100, B2:B100, d))),
    HSTACK(depts, totals)
)

' 返回两列：部门和总销售额
```

#### 案例 5：交叉表转换

```plaintext
' 将二维表转为一维表（动态数组）
=LET(
    products, A2:A10,
    months, B1:M1,
    data, B2:M10,
    rows, ROWS(products),
    cols, COLUMNS(months),
    seq, SEQUENCE(rows*cols),
    product_idx, MOD(seq-1, rows)+1,
    month_idx, INT((seq-1)/rows)+1,
    HSTACK(
        INDEX(products, product_idx),
        INDEX(months, 1, month_idx),
        INDEX(data, product_idx, month_idx)
    )
)
```

### D. 性能优化建议

1. **避免易失性函数过度使用**
   - TODAY(), NOW(), RAND(), OFFSET(), INDIRECT() 每次计算都会重新计算
   - 尽量用静态值替代

2. **减少整列引用**

   ```plaintext
   ' 不好
   =SUM(A:A)

   ' 好
   =SUM(A1:A1000)
   ```

3. **使用辅助列**
   - 复杂公式拆分为多步
   - 提高可读性和维护性

4. **优先使用 SUMIFS/COUNTIFS**
   - 比数组公式性能更好

5. **利用动态数组**
   - Excel 365 中动态数组公式更高效
