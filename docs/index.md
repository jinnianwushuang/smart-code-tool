# 读书的本质是一场合法抢劫。

- 如果你不花时间去创造你想要的生活，你将被迫花很多时间去应付你所不想要的生活。
- 成功的路上，没有人会叫你起床，也没有人会为你买单，你需要自我管理、自我约束、自我突破。
- 资本在收割你的注意力、意志力、思维能力，进而煽动情绪、篡改本能、磨灭理智。
 资本掠夺你的时间、金钱和健康，用算法驯服免费的奴隶，用你的人生作为燃料去供养成就他们。
