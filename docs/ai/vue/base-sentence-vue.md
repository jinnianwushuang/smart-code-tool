# VUE-基础提问语句

针对 Vue 开发环境，AI 最容易在 **Vue 3 组合式 API (Setup)、响应式丢失、组件通信**以及**全家桶配合**上产生幻觉。

这份模板专门针对 **Vue 3 + Vite + TypeScript** 体系进行了深度定制：

---

## 1. Vue 3 核心组件开发模板

> **策略：** 明确声明使用 `<script setup>` 和 TS，防止 AI 输出旧版的 Options API。

**Prompt 语句：**

> “你现在是一名 Vue 专家。请使用 **Vue 3 (`<script setup>`)** 和 **TypeScript** 帮我编写一个 **[组件名]**。
>
> **技术栈要求：**
>
> - **样式：** [如：Tailwind CSS / Scoped Less]
> - **组件库：** [如：Element Plus / Ant Design Vue / 无]
>
> **功能逻辑：**
>
> 1. [功能 1：如，通过 v-model 绑定输入值]
> 2. [功能 2：如，使用 defineExpose 暴露给父组件 open 方法]
>
> **代码规范：**
>
> - 使用 **Ref/Computed** 处理响应式。
> - 属性定义使用 `defineProps`，事件使用 `defineEmits` 并包含完整的 TS 类型。
> - 逻辑复杂的场景请提取到独立的 `useXXX` **Composables** 函数中。”

---

## 2. Vue 生态（Pinia/Router）集成模板

> **策略：** 强调状态管理的模块化和路由守卫的逻辑。

**Prompt 语句：**

> “我需要设计一个 **Pinia Store** 来管理 **[业务模块，如：用户信息]**。
>
> **要求：**
>
> 1. 使用 **Setup Store** 语法（即 `defineStore('id', () => { ... })`）。
> 2. **State：** 包含 [字段 1, 字段 2]。
> 3. **Getters：** [如：基于用户权限计算是否为管理员]。
> 4. **Actions：** 需要包含一个异步请求 [如：login]，并处理 Loading 状态。
> 5. **持久化：** 请展示如何配合 `pinia-plugin-persistedstate` 实现 [xx 字段] 的持久化。”

---

## 3. 指令/性能优化/难题攻关模板

> **策略：** 针对 Vue 的底层特性（自定义指令、生命周期、NextTick）。

**Prompt 语句：**

> “我遇到了一个 Vue 渲染相关的性能/逻辑难题。
>
> **问题场景：** [如：在 v-for 循环大列表时，点击按钮修改某个 item 导致全量重绘/卡顿]。
> **当前实现：**
>
> ```vue
> [粘贴相关片段]
> ```
>
> **请帮我：**
>
> 1. 分析是否因为 **Key** 使用不当或响应式追踪过深。
> 2. 提供优化方案（如：使用 `shallowRef`、`v-memo` 或 `Teleport`）。
> 3. 如果需要自定义指令实现 **[如：图片懒加载]**，请提供指令的完整实现代码。”

---

## 4. 针对 Vue 开发者的 4 个“提问必杀技”：

1. **版本强制：** 必须在开头加上 **“基于 Vue 3.4+ 版本”**，这样 AI 会倾向于使用更新的语法（如 `defineModel` 双向绑定简写）。
2. **样式穿透：** 遇到修改组件库样式失效时，问：**“在 Scoped 模式下如何使用 `:deep()` 正确覆盖 [组件名] 的样式？”**
3. **Hooks 提取：** 当你的组件超过 300 行，直接把代码丢给它：**“请帮我按照 Composition API 的最佳实践，将这段代码中的逻辑解耦为多个 Composable 函数。”**
4. **模版报错：** 遇到模板类型检查错误，问：**“Volar 提示这个 Prop 类型不兼容，如何在 `defineProps` 中正确定义带泛型的接口？”**
