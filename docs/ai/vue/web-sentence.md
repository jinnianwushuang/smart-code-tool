# 客户端-基础提问语句

针对 **客户端 H5（移动端）** 和 **PC 官网/门户** 场景，关注点会从后台系统的“效率与逻辑”转向 **“性能体验、交互细节、SEO 以及多端适配”**。

以下是为您定制的高频场景提问模板：

## 1. H5 丝滑列表（无限滚动与图片懒加载）

> **关注点：** 移动端内存管理、滑动卡顿、下拉刷新。

**Prompt 语句：**

> “请使用 **Vue 3 + [Vant/NutUI/无]** 开发一个 H5 端的 **[业务名，如：商品推荐]** 滚动列表。
> **要求：**
>
> 1. **无限滚动：** 实现触底自动加载分页数据，包含‘加载中’和‘没有更多了’的状态。
> 2. **下拉刷新：** 集成下拉刷新功能，并在数据重置时保持滚动条位置。
> 3. **图片优化：** 列表图需要支持 **懒加载**，并提供一张占位图（Placeholder）以防布局抖动。
> 4. **性能细节：** 请说明如何利用 `IntersectionObserver` 优化长列表，并确保在 iOS 滑动时没有白屏现象。”

---

## 2. PC 官网/门户（响应式与动画）

> **关注点：** 屏幕适配、SEO 友好、滚动视差效果。

**Prompt 语句：**

> “我正在使用 **Vue 3 + Tailwind CSS** 开发一个 PC 官网的 **[模块名，如：产品特性介绍]** 页面。
> **要求：**
>
> 1. **响应式适配：** 适配 1920px、1440px 以及平板端，确保间距和字体比例协调。
> 2. **入场动画：** 当用户滚动到该区域时，卡片逐个以 **[如：渐显向上浮动]** 的形式进入（建议使用 GSAP 或简单 CSS 动画）。
> 3. **交互：** 鼠标悬浮在卡片上时，有轻微的放大或阴影加深效果。
> 4. **SEO/结构：** 使用语义化标签（如 `<section>`, `article`, `h2`），并确保生成的 HTML 结构对 SEO 友好。”

---

## 3. H5 营销活动页（倒计时与表单）

> **关注点：** 倒计时精度、埋点、点击延迟。

**Prompt 语句：**

> “请帮我写一个 H5 活动抢购页面的 **[倒计时组件]**。
> **具体场景：** 距离活动结束还有 XX 小时 XX 分 XX 秒。
> **要求：**
>
> 1. **精度控制：** 使用 `requestAnimationFrame` 或校准算法解决 `setTimeout` 导致的计时偏差。
> 2. **状态控制：** 倒计时结束时，自动将‘立即报名’按钮置灰，并触发自定义事件。
> 3. **埋点：** 请在代码中预留 **数据埋点** 函数调用位置（如：进入页面、点击报名、报名成功）。
> 4. **移动端适配：** 使用 **px 转 rem/vw** 的适配方案，确保在不同尺寸手机上位置不偏移。”

---

## 4. 通用 移动端/PC 多端适配处理

> **关注点：**一套代码两端展示。

**Prompt 语句：**

> “我需要写一个 **[功能名，如：个人中心]** 模块，需要同时兼容 **移动端 H5 和 PC 端**。
> **策略：**
>
> 1. 请给出 **媒体查询（Media Queries）** 的编写思路。
> 2. 对于复杂的 UI 差异，请演示如何封装一个 `useDevice` Composable，通过判断 `isMobile` 在模板中动态切换布局。
> 3. 针对 PC 端的‘点击’和移动端的‘触摸’事件，是否有需要合并或区分处理的地方？”

---

## 💡 针对这两类场景的“进阶”提问技巧：

- **性能导向：** “请分析这段代码对 **LCP (最大内容绘制)** 和 **CLS (累积布局偏移)** 的影响，并给出优化建议。”
- **调试导向：** “我需要在这个 H5 页面中集成 **vConsole**，但只希望在测试环境下开启，请给出 Vite 配置方案。”
- **兼容性导向：** “这段 CSS 特性（如：`backdrop-filter`）在某些旧版安卓浏览器上无效，请提供降级方案。”
