# JS-基础提问语句

## JavaScript-基础提问语句

针对原生的 **JavaScript (ES6+)** 开发，AI 提问的重点应放在**逻辑严密性、代码健壮性（异常处理）以及性能表现**上。

以下是针对 JavaScript 四个高频场景的提问模板：

## 1. 复杂数据结构处理（数组/对象转换）

> **场景：** 处理后端返回的嵌套 JSON、数据脱敏、统计、排序、过滤。

**Prompt 语句：**

> “我有一组复杂的 **JSON 数据** [粘贴数据或描述结构]。
> **任务：** 请帮我编写一个纯函数，实现以下转换逻辑：
>
> 1. **过滤：** 剔除 [条件，如：状态为已取消] 的数据。
> 2. **转换：** 将数组平铺（Flatten）/ 将列表转为树状结构（Tree）。
> 3. **计算：** 统计出每个分类下的 [字段名] 总和。
>    **要求：** 优先使用 **ES6 数组方法**（如 `reduce`, `map`, `filter`），代码要简洁且具有高可读性，并包含边界情况处理（如数据为空）。”

---

## 2. 异步流程控制（Promise / Async-Await）

> **场景：** 多个接口并发、串行请求、接口重试、竞态处理。

**Prompt 语句：**

> “我需要处理一组 **异步请求**。
> **场景描述：** [如：需要并发请求 5 个接口，但必须等全部完成后再执行下一步；或者需要按顺序依次请求]。
> **具体要求：**
>
> 1. 使用 **async/await** 语法。
> 2. **错误处理：** 如果其中一个接口失败，[如：忽略它继续执行 / 立即报错退出]。
> 3. **超时机制：** 为每个请求设置 [3000ms] 的超时限制。
> 4. **竞态处理：** [可选：如果是搜索框输入，请确保只处理最后一次请求的结果，防止竞态冲突]。”

---

## 3. 工具函数封装（Utils / 业务逻辑解耦）

> **场景：** 编写防抖节流、深拷贝、日期处理、格式化。

**Prompt 语句：**

> “你现在是一名资深 JavaScript 工程师，请帮我封装一个通用的 **[功能名，如：深拷贝函数 / 自定义事件总线]**。
> **技术细节：**
>
> 1. **性能：** 考虑大数据的处理效率。
> 2. **健壮性：** 考虑循环引用问题（针对深拷贝）或 内存泄漏问题（针对事件总线）。
> 3. **环境：** 需同时兼容 **浏览器** 和 **Node.js** 环境。
> 4. **示例：** 请提供该函数的调用示例代码。”

---

## 4. DOM 操作与原生交互（Vanilla JS）

> **场景：** 编写不依赖框架的插件、性能分析、操作节点。

**Prompt 语句：**

> “我需要使用原生 JavaScript 实现一个 **[功能名，如：自定义弹窗插件 / 图片瀑布流布局]**。
> **要求：**
>
> 1. **DOM 操作：** 使用最新的 DOM API，避免使用 jQuery。
> 2. **性能优化：** 如果涉及频繁滚动或窗口缩放，请集成 **[防抖/节流]** 逻辑。
> 3. **样式隔离：** 动态创建的元素需保证样式不污染全局（建议使用 JS 动态注入 CSS 或内联样式）。
> 4. **交互：** 点击元素外部时自动关闭/销毁该实例。”

---

## 💡 提升 JS 提问质量的 3 个“专业后缀”：

- **追求现代感：** “请不要使用 `var`，完全使用 **ES2020+** 的语法（如可选链 `?.` 和空值合并 `??`）。”
- **追求性能：** “请分析这段代码的时间复杂度和空间复杂度，并给出 **Big O 优化** 后的版本。”
- **追求规范：** “请按照 **Airbnb JavaScript Style Guide** 的规范来编写这段代码。”
