# 架构师（P8）学习路径

> 架构师的核心目标是「做决策」——技术战略、架构设计、跨团队影响力，用技术驱动业务价值。

## 级别特征

```
核心要求：
├── 技术战略与业务理解
├── 复杂系统架构设计
├── 技术选型与权衡决策
├── 跨团队技术影响力
├── 性能/安全/可扩展性全局把控
├── 技术团队建设与培养
└── 行业趋势洞察

面试重点：
├── 架构决策能力（为什么选 A 不选 B）
├── 系统设计（大型复杂系统）
├── 技术视野（行业趋势）
├── 业务理解（技术如何创造价值）
└── 领导力与影响力
```

## 架构师核心能力

```
技术能力：
├── 系统设计 → 拆分、扩展、演进
├── 性能优化 → 全局视角、瓶颈定位
├── 安全架构 → 攻防体系、合规策略
├── 技术选型 → 权衡决策、长期规划
└── 趋势洞察 → 技术雷达、行业判断

软技能：
├── 沟通影响 → 跨团队协作、技术布道
├── 决策能力 → 权衡利弊、承担责任
├── 团队建设 → 人才培养、梯队建设
└── 业务理解 → 技术价值、ROI 思维
```

## 建议学习顺序

```
第 1-2 周：架构设计（5 篇）→ 架构思维
第 3-4 周：系统设计（4 篇）→ 复杂系统设计
第 5-6 周：工程化/DevOps（3 篇）→ 工程体系
持续：关注行业动态、参与技术社区、积累实战案例
```

## 晋升到技术主管

完成架构师内容后，建议继续学习 [技术主管](/interview/levels/manager) 内容，重点深入：

- 团队管理与人才培养
- 技术规划与项目管理
- 跨部门协作与沟通
