# 技术主管（TL）学习路径

> 技术主管的核心目标是「带团队」——技术规划、团队管理、跨部门协作，用技术驱动业务成功。

## 级别特征

```
核心要求：
├── 技术规划与路线图
├── 团队建设与人才培养
├── 项目管理与交付能力
├── 跨部门沟通与协作
├── 技术决策与风险评估
├── 业务理解与价值导向
└── 技术文化与氛围建设

面试重点：
├── 管理经验（带过什么团队）
├── 技术规划（如何制定路线图）
├── 人才培养（如何带人成长）
├── 冲突处理（如何解决问题）
└── 业务理解（技术如何服务业务）
```

## 技术主管核心能力

```
技术能力：
├── 技术规划 → 路线图、里程碑
├── 架构决策 → 技术选型、权衡
├── 质量把控 → 代码规范、Review
└── 风险预判 → 技术债务、瓶颈识别

管理能力：
├── 团队管理 → 招聘、培养、绩效
├── 项目管理 → 计划、执行、交付
├── 沟通协作 → 跨部门、向上管理
└── 文化建设 → 技术氛围、知识分享

业务理解：
├── 业务价值 → 技术如何服务业务
├── ROI 思维 → 投入产出评估
└── 战略对齐 → 技术规划对齐业务
```

## 建议学习顺序

```
第 1-2 周：管理与领导力（5 篇）→ 管理思维
第 3-4 周：工程化/DevOps（3 篇）→ 工程体系
持续：实践管理技能、积累管理经验、反思总结
```

## 技术主管成长路径

```
初级主管 → 关注任务执行、团队稳定
├── 中级主管 → 关注团队成长、流程优化
├── 高级主管 → 关注战略规划、业务价值
└── 总监/VP → 关注组织发展、技术战略
```
